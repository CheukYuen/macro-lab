# 错误码速查

调用任一 API 后，如果是 EmQuantData 类型，先看返回对象的 `ErrorCode`；非 0 即失败，按下表按含义定位原因。激活相关错误码（`10001020` / `10001019` / `10001009`）的处理见 [sdk-setup.md §3](../sdk-setup.md#3-常见激活错误码)；本表只列含义，不含逐码解决方案。

---

## 成功

| 错误码 | 错误标识 | 含义 |
| --- | --- | --- |
| 0 | `EQERR_SECUSS` | 调用成功 |

---
