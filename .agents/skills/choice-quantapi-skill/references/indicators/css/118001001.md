|参数编号|英文简称|中文说明|取值范围|默认值|
|---|---|---|---|---|
|1|EndDate|截止日期||获取规则：最新日期|
|2|FundCategory|基金分类|1 东财基金一级分类<br>2 东财基金二级分类<br>3 东财基金三级分类<br>6 人社部养老金产品一级分类<br>7 人社部养老金产品二级分类|1|
