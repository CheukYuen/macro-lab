# 04 新闻与事件

目标：把新闻加工成可复用、可推理、低主观的事件输入，并在周频上形成资产主线。原项目有两份文档：新闻加工 P0 规范（团队人工加工）与事件引擎设计（LLM + 规则自动化）。样本见 `appendix/news/key-news-sample.csv`。

## 1. 硬事件（新闻加工 P0 规范）

**硬事件 = 有明确主体、动作、对象和时间，可被验证的客观事件。**

| 是硬事件 | 不是硬事件 |
| --- | --- |
| 央行下调存款准备金率 | 市场风险偏好提升 |
| 美国宣布对芯片加征关税 | 产业链景气度上行 |
| 国务院发布企业信用评价体系意见 | 通胀压力加大 |
| 伊朗就霍尔木兹海峡通行释放强硬表态 | 资金开始回流科技板块 |

五项加工原则：

1. **一条新闻一个主事件**：不混入市场反应、媒体评论、券商观点。
2. **删除解释性词语**：景气度提升、扰动加大、明显上涨、意味着、反映出……多写事实，少写解释。
3. **标题写事件，不写反应**：写「美国拟对部分药品和芯片加征新关税」，不写「芯片板块承压」「国际油价大涨」。
4. **优先保留硬事件**：政策发布、制度变化、监管动作、关税、地缘与外交表态、官方数据；不留综述、盘后总结、拼盘、纯评论。
5. **事件簇去重**：同一事件只留最接近原始动作的一条，去重是事件层面而非文本层面。

## 2. 原子事件引擎（自动化设计）

**原子事件 = 不含推理、只描述已发生变化的最小市场事实单元。** 三个条件：可验证（主体／动作／结果）、单跳因果、可映射到至少一类资产。

### 2.1 P0 筛选

| 条件 | 保留 | 丢弃 |
| --- | --- | --- |
| 影响范围 | 全市场／大类资产 | 个股／单行业 |
| 市场反应（辅助观察） | 已有价格、利率或数据反应 | 不作为丢弃依据 |
| 机制 | 作用路径清晰（流动性／供给／信用） | 无法解释 |
| 重复 | 新事件 | 同事件不同表述 |

### 2.2 流程

```text
新闻 → LLM 宽松提取 {subject, action, object, result}
     → 规则校验：字段非空；action 在白名单（封锁/投放/回笼/上调/下调/增加/减少/违约/扩大/收紧/放松）；
                 result 必须是变化（上涨/下跌/受阻/净投放/净回笼/收紧/放松）；不通过即丢弃
     → LLM 受限抽象：{event, event_type, transmission_path, asset_class, impact_direction, market_validation, key_signal}
     → 日频事件库 → 周频主线聚合（每类资产 1～3 个主线事件）
```

强约束：传导路径只允许 1 个（至多 2 个紧邻）；禁止跨变量推理（事件 → 通胀 → 利率 → 股票交给推理层）；方向判断须注明依据，不能仅凭价格反应确认因果；不允许「预期／可能／或将」。

价格反应是辅助观察，不是因果证明。用于行业／公司研究时，有来源的政策、订单等事件即使尚无价格反应，也可进入研究。

### 2.3 标签体系

| 字段 | 取值 |
| --- | --- |
| event_type | 货币政策、财政政策、地缘政治、信用事件、供给冲击、流动性变化 |
| transmission_path | 流动性、供给、信用、利率（仅当已发生） |
| asset_class | 股票类、固收类、另类资产、现金类 |

### 2.4 案例

```json
{"subject": "央行", "action": "逆回购操作", "object": "5000亿元", "result": "净回笼资金"}
→
{"event": "流动性边际收紧", "event_type": "货币政策", "asset_class": ["现金类", "固收类"],
 "transmission_path": ["流动性"], "impact_direction": {"资金面": "偏紧"},
 "market_validation": {"操作结果": "净回笼"}, "key_signal": ["缩量续作", "净回笼资金"]}
```

霍尔木兹案例只写到「原油运输受阻 → 供给紧张 → 原油上涨」，不写通胀、利率、股票。

## 3. 喂给月报的新闻 schema

```csv
news_id,title,context,summary,event_id,sentiment_label,related_indicators,impact_level,data_type,affected_asset_classes,priority_asset_class
```

- `event_id`：事件归一化 ID，如 `GEOPOLITICS_HORMUZ_SUPPLY_SHOCK`、`POLICY_INDUSTRIAL_CHN_COMPUTING_INCENTIVE`（类别_地区_主题）。
- `related_indicators`：关联到 `01` 指标字典中的 indicator_id，打通新闻与宏观数据。
- `sentiment_label`：Positive／Negative／Neutral；`impact_level`：High／Medium／Low。
- 早期版本用 `sentiment_score`（-1～1）与 `source`、`datetime`，后改为标签并去掉来源时间（溯源上是退步，见 `06`）。

## 4. 两份文档的分歧

- 新闻规范说标题不写市场反应；事件引擎要求必须有价格验证。可以兼容：反应写进 `market_validation`，不进标题与事件本体。
- 事件引擎排除个股／单行业新闻，只服务大类资产；做行业／公司研究时必须放开这一条（见 `07`）。
