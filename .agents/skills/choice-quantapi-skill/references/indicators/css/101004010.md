|参数编号|英文简称|中文说明|取值范围|默认值|

|1|ReportDate|报告期||获取规则：去年年报|

|3|YesNo|方案是否通过|1 是<br>0 否|1|
|4|Payyear|年度||2026|
|5|Payyear|年度(范围)||2026|
