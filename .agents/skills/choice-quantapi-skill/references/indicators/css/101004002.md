# 截面函数 / 股票 / 三板股指标分类 / 股本指标

## 指标说明

下表是每个指标特有参数的说明，公共参数参见[css函数说明文档]<!-- agent only: (./../../functions/css.md)-->【3. 公共参数】部分。

|中文简称|英文简称|参数1|单位|精度|释义|
|---|---|---|---|---|---|
|总股本|TOTALSHARE|截止日期[1]|||在指定日期，公司已发行的普通股股份总数（不含优先股）。注：1.股份变动日以除权日为准（这样做是为了与行情除权同步，方便用户计算总市值、PE等行情相关指标）2.CDR品种的基本单位为”份“，指标未进行换算。<!-- 目录：股票 / 三板股指标分类 / 股本指标 -->|
|流通A股|LIQASHARE|截止日期[1]|||在指定日期，公司已发行的境内上市流通、以人民币兑换的股份总数。<!-- 目录：股票 / 三板股指标分类 / 股本指标 -->|
|流通A股(含锁定股)|LIQAADDEXECUTIVESHARE|截止日期[1]|||在指定日期，公司已发行的境内上市流通、以人民币兑换的股份总数，包含高管锁定股。<!-- 目录：股票 / 三板股指标分类 / 股本指标 -->|
|限售A股|RESTRICTEDASHARE|截止日期[1]|||限售A股是限售股中，解禁时转入流通A股的股份数。<!-- 目录：股票 / 三板股指标分类 / 股本指标 -->|
|A股合计|TOTALASHARE|截止日期[1]|||公司已发行的，境内上市，以人民币兑换的普通股股份总数（含限制流通股），也称为人民币普通股。<!-- 目录：股票 / 三板股指标分类 / 股本指标 -->|
|流通B股|LIQBSHARE|截止日期[1]|||在指定日期，公司已发行的境内上市流通、以外币兑换的股份总数，也称为境内上市外资股（简称B股）。<!-- 目录：股票 / 三板股指标分类 / 股本指标 -->|
|限售B股|RESTRICTEDBSHARE|截止日期[1]|||限售股份解禁时转入流通B股的股份数。<!-- 目录：股票 / 三板股指标分类 / 股本指标 -->|
|B股合计|TOTALBSHARE|截止日期[1]|||公司已发行的，境内上市，以人民币兑换的股份总数，也称为境内上市外资股（简称B股）。<!-- 目录：股票 / 三板股指标分类 / 股本指标 -->|
|无限售流通股合计|TOTALLIQSHARE|截止日期[1]|||在指定日期，公司已发行的可以在合法的证券交易市场公开交易的各类股票股份总数<!-- 目录：股票 / 三板股指标分类 / 股本指标 -->|
|限售股合计|TOTALRESTRICTEDSHARE|截止日期[1]|||限售股份的合计数<!-- 目录：股票 / 三板股指标分类 / 股本指标 -->|
