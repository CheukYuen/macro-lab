## 指标说明

下表是每个指标特有参数的说明，公共参数参见[css函数说明文档]<!-- agent only: (./../../functions/css.md)-->【3. 公共参数】部分。

|中文简称|英文简称|参数1|单位|精度|释义|
|---|---|---|---|---|---|
|净资产收益率ROE|DUPONTROE|报告期[1]|%|0.0000|杜邦分析即通过因素分解法，寻找“净资产收益率”增减变动的原因。传统杜邦分析有三因素法和五因素法。Choice资讯将“净资产收益率”分解为“归属母公司股东的净利润占比”、“销售净利率”、“资产周转率”、“权益乘数”四个主要因素，其中“销售净利率”还可以进一步分解为“税负水平”、“利息负担”、“经营利润率”。净资产收益率=归属母公司股东的净利润占比*销售净利率*资产周转率*权益乘数归属母公司股东的净利润占比=归属母公司股东的净利润/净利润；销售净利率=净利润/营业总收入；资产周转率=营业总收入/平均总资产；权益乘数=平均总资产/归属母公司股东的权益其中，“销售净利率”还可以再分解为反映税负水平、利息负担、经营利润率的指标，如下：销售净利率=（净利润/利润总额）*（利润总额/息税前利润）*（息税前利润/营业总收入）净利润/利润总额：反映企业税负水平；利润总额/息税前利润：反映企业利息负担；息税前利润/营业总收入：反映企业经营利润率。<!-- 目录：股票 / 三板股指标分类 / 财务分析 / 杜邦分析 -->|
|权益乘数(杜邦分析)|DUPONTASSETSTOEQUITY|报告期[1]|无|0.0000|反映企业财务杠杆效应强弱和财务风险。关于“杜邦分析”的因素分解方法参见“净资产收益率ROE—杜邦分析”。<!-- 目录：股票 / 三板股指标分类 / 财务分析 / 杜邦分析 -->|
|总资产周转率|DUPONTASSETTURN|报告期[1]|次|0.0000|反映企业资产管理效率的指标。关于“杜邦分析”的因素分解方法参见“净资产收益率ROE-杜邦分析”。<!-- 目录：股票 / 三板股指标分类 / 财务分析 / 杜邦分析 -->|
|归属母公司股东的净利润/净利润|DUPONTPNITONI|报告期[1]|%|0.0000|反映母公司控股子公司百分比。如果企业追加投资，扩大持股比例，则本指标会增加。关于“杜邦分析”的因素分解方法参见“净资产收益率ROE-杜邦分析”。<!-- 目录：股票 / 三板股指标分类 / 财务分析 / 杜邦分析 -->|
|净利润/营业总收入|DUPONTNITOGR|报告期[1]|%|0.0000|反映企业销售获利率。关于“杜邦分析”的因素分解方法参见“净资产收益率ROE-杜邦分析”。<!-- 目录：股票 / 三板股指标分类 / 财务分析 / 杜邦分析 -->|
|净利润/利润总额|DUPONTTAXBURDEN|报告期[1]|%|0.0000|反映企业税负水平，该比值高则税负较低。净利润/利润总额=1-所得税/利润总额。关于“杜邦分析”的因素分解方法参见“净资产收益率ROE-杜邦分析”。<!-- 目录：股票 / 三板股指标分类 / 财务分析 / 杜邦分析 -->|
|利润总额/息税前利润|DUPONTINTBURDEN|报告期[1]|%|0.0000|反映企业利息负担，该比值高则税负较低。利润总额/息税前利润=1-利息费用/息税前利润关于“杜邦分析”的因素分解方法参见“净资产收益率ROE-杜邦分析”。<!-- 目录：股票 / 三板股指标分类 / 财务分析 / 杜邦分析 -->|
|息税前利润/营业总收入|DUPONTEBITTOGR|报告期[1]|%|0.0000|反映企业经营利润率，是企业经营获得的可供全体投资人（股东和债权人）分配的盈利占企业全部经营收入的百分比。关于“杜邦分析”的因素分解方法参见“净资产收益率ROE-杜邦分析”。<!-- 目录：股票 / 三板股指标分类 / 财务分析 / 杜邦分析 -->|
