# 日期宏

> 日期参数中可直接使用字母替代或加减法运算获取对应日期；分为相对日期和绝对日期。

---

## 1. 相对日期

| 相对日期 | 参数英文 | 描述 |
| --- | --- | --- |
| 交易日 | `TD` | 搭配 `Market` 参数，可按照指定市场交易日历返回；默认 `CNSESH`（上交所）。市场列表参考各函数页的 `Market` 参数说明。 |
| 日历日 | `D` | 日历日。 |
| 日历周 | `W` | 日历周。 |
| 日历月 | `M` | 日历月。 |
| 日历季 | `Q` | 日历季。 |
| 日历半年 | `HY` | 日历半年。 |
| 日历年 | `Y` | 日历年。 |
| 开始日期 | `SD` | 引用标识。例如 `StartDate="20221020"` 时，可设置 `EndDate="SD+5D"`，表示取 2022-10-20 之后 5 天的日期区间。 |
| 截止日期 | `ED` | 引用标识。例如 `EndDate="20221020"` 时，可设置 `StartDate="ED-5D"`，表示取截止日期前 5 天到截止日的日期区间。 |

---

## 2. 绝对日期

| 绝对日期 | 参数英文 | 描述 |
| --- | --- | --- |
| 上市首日 | `S` | 仅支持 `css` / `csd`。 |
| 最新 | `N` | 最新日期 / 今天（具体口径以接口返回为准）。 |
| 最新报告期 | `MRQ` | 仅支持 `css`。 |
| 去年一季 | `LQ1` | 去年一季。 |
| 去年中报 | `LQ2` | 去年中报。 |
| 去年三季 | `LQ3` | 去年三季。 |
| 去年年报 | `LQ4` | 去年年报。 |
| 今年一季 | `RQ1` | 今年一季。 |
| 今年中报 | `RQ2` | 今年中报。 |
| 今年三季 | `RQ3` | 今年三季。 |
| 今年年报 | `RQ4` | 今年年报。 |
| 本年初 | `RYF` | 本年初。 |
| 本周一 | `RWF` | 本周一。 |
| 本月初 | `RMF` | 本月初。 |
| 上周末 | `LWE` | 上周末。 |

---

## 3. 运算规则

1. 支持加减法运算，例如：
   - `ED-10D`：从截止日前推 10 天；
   - `SD+5TD`：从开始日往后推 5 个交易日。
2. 运算中，数字代表 N 个周期，只支持整数。
3. 负号 `-` 代表前推；没有负号或用加号 `+` 代表后推。
4. 不带 `SD` / `ED` 引用标识时，默认从最新日期开始推，例如 `-5D` 表示从最新日期往前推 5 天。

---

## 4. 示例

```text
StartDate=-1W,EndDate=N
```

起始日期为 1 个周前，截止日期为最新日期。

```text
ReportDate=MRQ
```

报告期为最新报告期。

```text
StartDate=ED-5D,EndDate=20221020
```

取截止日期前 5 天到截止日的日期区间。

```text
StartDate=-5TD,EndDate=N,Market=CNSESH
```

按上交所交易日历，从最新日期往前 5 个交易日至最新日期。注意：区间函数通常包含起止端点；如需精确控制返回日期条数，建议先用 `tradedates` 验证日期列表。
