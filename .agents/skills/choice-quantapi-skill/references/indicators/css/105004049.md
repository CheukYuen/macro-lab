# 截面函数 / 指数 / 财务指标 / 每股指标

## 指标说明

下表是每个指标特有参数的说明，公共参数参见[css函数说明文档]<!-- agent only: (./../../functions/css.md)-->【3. 公共参数】部分。

|中文简称|英文简称|参数1|单位|精度|释义|
|---|---|---|---|---|---|
|每股收益EPS|EPSBASIC|报告期[1]|元|0.0000|上市公司定期报告中披露的基本每股收益(2006年报以前的名称为“加权每股收益”)。   每股收益是衡量上市公司盈利能力最常用的财务指标，反映普通股的获利水平。该指标不反映股票所含有的风险。<!-- 目录：指数 / 财务指标 / 每股指标 -->|
|每股收益EPS(TTM)|EPSTTM|交易日期[2]|||指数成份股归属于母公司股东的净利润（TTM）之和除以成份股总股本<!-- 目录：指数 / 财务指标 / 每股指标 -->|
|每股净资产BPS|BPS|交易日期[2]|||指数成份股归属于母公司股东的权益之和除以成份股总股本之和<!-- 目录：指数 / 财务指标 / 每股指标 -->|

## 参数说明

> 默认值中以**获取规则**开头的内容，需要按照规则获取相应日期作为默认值。

|参数编号|英文简称|中文说明|取值范围|默认值|
|---|---|---|---|---|
|1|ReportDate|报告期||获取规则：最新一期（MRQ）|
|2|TradeDate|交易日期|字符串，支持YYYYMMDD,YYYY-MM-DD,YYYY/MM/DD，例：20160101|获取规则：最新日期|
