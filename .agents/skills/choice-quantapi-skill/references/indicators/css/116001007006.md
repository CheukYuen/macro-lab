# 截面函数 / 机构 / 券商指标 / 财务分析 / 偿债能力

## 指标说明

下表是每个指标特有参数的说明，公共参数参见[css函数说明文档]<!-- agent only: (./../../functions/css.md)-->【3. 公共参数】部分。

|中文简称|英文简称|参数1|单位|精度|释义|
|---|---|---|---|---|---|
|产权比率|LIBILITYTOEQUITY|报告期[1]|无|0.0000|产权比率是负债总额与股东权益总额之比率，也叫作债务权益比率，是衡量长期偿债能力的指标之一。<!-- 目录：机构 / 券商指标 / 财务分析 / 偿债能力 -->|
|归属母公司股东的权益/负债合计|EQUITYTOLIBILITY|报告期[1]|无|0.0000|企业净资产与全部债务的比值，是衡量债务安全性的指标之一。<!-- 目录：机构 / 券商指标 / 财务分析 / 偿债能力 -->|
|经营活动产生的现金流量净额/负债合计|CFOTOLIBILITY|报告期[1]|无|0.0000|该指标又名“现金债务总额比”，该比率越高，公司承担债务能力越高。<!-- 目录：机构 / 券商指标 / 财务分析 / 偿债能力 -->|
