## 指标说明

下表是每个指标特有参数的说明，公共参数参见[css函数说明文档]<!-- agent only: (./../../functions/css.md)-->【3. 公共参数】部分。

|中文简称|英文简称|参数1|单位|精度|释义|
|---|---|---|---|---|---|
|留存收益/资产总额|RETAINEDEARNINGSASSET|报告期[1]|%|0.0000|反映公司的累积盈利能力。一般说来，新公司相对老公司来说，累计盈利相对占劣势，财务危机的风险相对较大。<!-- 目录：股票 / 港股及美股指标 / 财务分析 / Z值预警 -->|
|股东权益合计/负债总计|EQUITYDEBT|报告期[1]|%|0.0000|是反映一家公司财务结构和所有者权益与债权人权益相对关系的比率，可以反映一家公司的偿债能力。<!-- 目录：股票 / 港股及美股指标 / 财务分析 / Z值预警 -->|
|营运资本/总资产|CAPITALTOASSETS|报告期[1]|%|0.0000|反映资产的变现能力和规模特征；一个持续亏损的公司，财务危机的风险相对较大。<!-- 目录：股票 / 港股及美股指标 / 财务分析 / Z值预警 -->|
