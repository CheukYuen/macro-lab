# 错误与限制

网页与方法核对不等于金融序列可用性、历史时点版本或数据权限已验证。

- 若干 IMF eLibrary 页面返回 403 或 Internal Error，早期 BPM 链接有 404；已成功打开 ECB 财政方法 PDF 及 IMF BPM6 Compilation Guide，分别核读财政测量/实时修订和 §8.102—8.103 符号规则。IMF CAPB 潜在 GDP/净利息细项仍需正式采用版原件复核，01 明示限制；不阻塞详细设计。
- Ledoit 原文 PDF 正文工具读取失败、RiskMetrics 全文有访问形式限制；03 仅采用已核对的原作者摘要/方法介绍和明示递推定义，不声称复现论文或采用参数。
- 文档方法复核发现两项实际定义缺陷：03 资产上限的穿透计入不足；04 真实系统重放的入站时点约束过晚。修订与复查状态见 run-state.md，原始复核见 design-review.md。
- 文档公式初稿外层转义过度，03 原作者已改为标准行内/块级美元符号；未编写或运行投资模型。
