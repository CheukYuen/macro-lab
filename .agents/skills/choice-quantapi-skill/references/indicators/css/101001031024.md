## 指标说明

下表是每个指标特有参数的说明，公共参数参见[css函数说明文档]<!-- agent only: (./../../functions/css.md)-->【3. 公共参数】部分。

|中文简称|英文简称|参数1|参数2|单位|精度|释义|
|---|---|---|---|---|---|---|
|区间回购次数|REPURNUMP|起始交易日期[1]|截止交易日期[2]|-|-|统计区间内股权回购次数，以股票回购预案公告的次数为基准进行计算。<!-- 目录：股票 / 沪深京股票指标 / 股票回购 / 区间回购指标 -->|
|区间回购数量|REPURVOLP|起始交易日期[1]|截止交易日期[2]|-|-|统计区间内已实施的股权回购股数。<!-- 目录：股票 / 沪深京股票指标 / 股票回购 / 区间回购指标 -->|
|区间回购金额|REPURMONEYP|起始交易日期[1]|截止交易日期[2]|-|-|公告日期在统计区间内已实施的股权回购金额。<!-- 目录：股票 / 沪深京股票指标 / 股票回购 / 区间回购指标 -->|

## 参数说明

> 默认值中以**获取规则**开头的内容，需要按照规则获取相应日期作为默认值。

|参数编号|英文简称|中文说明|取值范围|默认值|
|---|---|---|---|---|
|1|StartDate|起始交易日期||获取规则：截止日1年前|
|2|EndDate|截止交易日期||获取规则：最新日期|
