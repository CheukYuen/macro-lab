## 参数说明

> 默认值中以**获取规则**开头的内容，需要按照规则获取相应日期作为默认值。

|参数编号|英文简称|中文说明|取值范围|默认值|
|---|---|---|---|---|
|1|StartDate|起始交易日期||获取规则：截止日52周前|
|2|EndDate|截止交易日期||获取规则：最新日期|
|3|Nmonths|月数|3 3个月<br>6 6个月<br>12 12个月<br>24 24个月|6|
|4|TradeDate|交易日期|字符串，支持YYYYMMDD,YYYY-MM-DD,YYYY/MM/DD，例：20160101|获取规则：最新日期|
|5|FundCategory|基金分类3|1 运作方式<br>2 东财基金一级分类<br>3 东财基金二级分类<br>4 东财基金三级分类<br>5 概念分类<br>6 人社部养老金产品一级分类<br>7 人社部养老金产品二级分类|1|
|6|ComputingCycle|计算周期|1 日<br>2 周<br>3 月<br>4 年|3|
|7|EndDate|截止日期||获取规则：最新日期|
