# ctr 报表清单导航

> 适用函数：[ctr 专题报表函数](../functions/ctr.md)
>
> ctr 函数返回的是一整张「报表」，没有传统意义上的"指标目录"。本页是报表清单的**二级导航**，按业务大类指向报表详情页；[functions/ctr.md#6-代表报表示例非完整索引](../functions/ctr.md#6-代表报表示例非完整索引) 仅保留少量代表报表示例。

---

## 使用方式

1. 在下方分类导航中选定业务方向；
2. 打开对应报表详情页，复制报表代码（`ctrName`）、字段简称和参数说明；
3. 按详情页说明拼接 `indicators` 和 `options`；
4. 调用 `ctr(ctrName, indicators, options)`。
