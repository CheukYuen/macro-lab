# cses 指标目录主索引

> 适用函数：[cses 板块截面函数](../functions/cses.md)
>
> 本页是 cses 函数能用的指标目录的"二级导航"。每行给出：目录（可点击跳转详情） → 指标的简绍。

---

## 使用方式

1. 通读下方目录，按"业务大类"找到所需的指标目录；
2. 点击「详情页」打开该目录的完整指标清单；
3. 复制指标英文简称（如 `TOTALSHARE`）与其特有参数；
4. 回到 [cses 命令拼接教程](../functions/cses.md#5-命令拼接教程) 拼接 `options`，调用。
