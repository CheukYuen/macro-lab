|MFI资金流向指标|MFIZJLXZB|交易日期[1]|周期[2]|复权方式[3]|计算周期[4]|||-|0.0000|MFI指标实际是将RSI加以修改后演变而来。RSI以成交价为计算基础；MFI指标则结合价和量，将其列入综合考虑的范围。可以说，MFI指标是成交量的RSI指标。1.MFI>80 为超买，当其回头向下跌破80 时，为短线卖出时机； 2.MFI<20 为超卖，当其回头向上突破20 时，为短线买进时机； 3.MFI>80，而产生背离现象时，视为卖出信号； 4.MFI<20，而产生背离现象时，视为买进信号。<!-- 目录：股票 / 港股及美股指标 / 技术指标 / 量价指标 -->|

## 参数说明

> 默认值中以**获取规则**开头的内容，需要按照规则获取相应日期作为默认值。

|参数编号|英文简称|中文说明|取值范围|默认值|
|---|---|---|---|---|
|1|TradeDate|交易日期|字符串，支持YYYYMMDD,YYYY-MM-DD,YYYY/MM/DD，例：20160101|获取规则：最新日期|
|2|N|周期||14|
|3|AdjustFlag|复权方式|1 不复权<br>2 后复权<br>3 前复权|1|
|4|Period|计算周期|1 日<br>2 周<br>3 月<br>4 季<br>5 半年<br>6 年|1|
|5|Obv|OBV指标选项|1 OBV<br>2 修正OBV|1|
|6|N1|周期1||24|
|7|N2|周期2||6|
|8|Wvad|WVAD指标选项|1 WVAD<br>2 MAWVAD|1|
