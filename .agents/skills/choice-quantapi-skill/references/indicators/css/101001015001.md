|---|---|---|---|---|---|
|首发发行方式|IPOTYPE||-||上市公司发行新股，可以向社会公开募集，也可以向原股东配售。实务上，我国上市公司新股发行主要以向社会公开募集发行为主，对一些大盘股则以公开募集和配售相结合的方式进行发行。询价制度实施以后，我国新股发行则以公开募集和配售相结合的方式进行。<!-- 目录：股票 / 沪深京股票指标 / 首发(IPO)指标 / 发行方式与承销商明细 -->|
