# 数据口径与验证设计

本章规定将来如何把指标和资产定义变成可使用的数据，以及怎样证明模型没有依赖当时未知的信息。当前只确定契约和验收方法，不创建数据库、不接入数据、不运行回测。

## 1 数据可获取之后仍需解决的问题

数据供应不再限制研究池的广度，但一个序列是否适合模型，仍取决于定义、历史版本、可比较性和决策时间。尤其要区分：今天能下载的历史数据、历史上当时公开的数据、以及当时本系统实际收到的数据。

同一指标允许有多个原始来源和多个特征，但每个被采用的特征必须有确定口径。官方机构负责定义和原始发布，供应商提供分发、标准化与检索，研究者负责采用与转换；两个供应商转发同一官方值不构成两份独立经济证据。

方法依据：ALFRED 提供历史日期上可见的数据版本，但其发布日期在原始来源不可得时也可能使用数据商日期或首次进入 FRED 的日期。因此，“带 vintage 标签”不自动意味着具备精确到分钟的原始发布时间。[ALFRED 方法说明](https://alfred.stlouisfed.org/help)、[版本与有效区间说明](https://alfred.stlouisfed.org/help/downloaddata)。

## 2 四种对象与六个时间

### 2.1 对象边界

| 对象 | 回答的问题 | 最小内容 | 不承载什么 |
| --- | --- | --- | --- |
| 指标定义 `series_definition` | 这是什么 | 稳定 ID、经济含义、地区、人群、币种、单位、原始频率、季调、口径版本、来源机构 | 不把供应商代码当经济定义 |
| 观察版本 `observation_vintage` | 某期数值在何时被知道 | 观察期、值、版本发布时间、来源与定位、取得时间、缺失状态 | 不覆盖旧修订值 |
| 特征定义及快照 `feature_snapshot` | 决策时使用了什么变换 | 输入版本、公式、训练窗口、变换参数、截点、输出、质量状态 | 不将估算伪装成原始事实 |
| 资产收益及组合版本 `return_snapshot / portfolio_version` | 哪种可比收益和风险 | 基准版本、总收益类型、币种、对冲、成本、成分、持仓时点、再平衡规则 | 不把产品净值、纯价格、经济因子混为一类 |

元数据采用表格或轻量契约即可；逻辑对象不等于必须建设四个服务或数据库。若进入实施，先在现有 `invest-sources` 与研究交接规则下验证一个样本，再决定存储形态。

### 2.2 时间字段

| 字段 | 含义 | 必须避免的混淆 |
| --- | --- | --- |
| `observation_start / end` | 数据描述的经济期间或市场观察时间 | 9 月统计数不代表 9 月末已发布 |
| `original_release_at` | 该观察值首次公开的时间 | 与报告期、下载日分开 |
| `vintage_published_at` | 本次修订版本公开的时间 | 旧报告期的新修订不能回填到旧截点 |
| `provider_available_at` | 数据渠道可见时间，能证实时记录 | 分发延迟可能使公开值暂时不可交易使用 |
| `retrieved_at` | 本系统实际取得时间 | 后来下载并不自动否定真实历史版本，但不能声称系统当时已收到 |
| `decision_at / earliest_execution_at` | 决策冻结与最早允许执行的时间 | 先看到收盘值再用同一收盘价成交属于理想化假设 |

所有时间保留原始时区并有 UTC 对应；日历绑定 `Asia/Shanghai`、`America/New_York` 等 IANA 时区以处理夏令时。只知日期则标 `time_precision=date`，不能补成 00:00 冒充精确时间。历史日内可用时间未知时，采用披露日结束后下一可交易时点的保守规则，并记录该假设。

截点选择规则：对某观察期，只在 `vintage_published_at ≤ decision_at` 的合格版本中取最新一个。“公开信息可得性重建”还应按当时渠道与处理延迟设定可用时点，要求特征在决策冻结前形成；不能因为成交发生得更晚，就使用冻结之后才到达的信息。“系统历史实盘重放”则必须有日志证明该输入已在 `decision_at` 前实际收到、校验并完成特征处理；成交时间只决定冻结之后最早能如何执行，不扩大信息集。

今天取得的原始旧版本可以用于公开信息重建，不能冒称系统当时已收到。缺少实际入站日志的延迟假设应标为模拟；只保存最新修订值的序列不得进入严格的历史信号验证。

## 3 指标与特征的详细字段

| 字段组 | 必填项 | 采用规则 |
| --- | --- | --- |
| 身份 | `series_id, definition_version, feature_id, feature_version` | 原始序列与派生特征分 ID；名称改写不改变定义，统计口径改变须新版本或新序列 |
| 经济定义 | `measure, geography, sector, population, currency, unit, scale` | 名义/实际、存量/流量、总量/人均、企业/居民、全国/样本分别标明 |
| 统计口径 | `frequency, seasonal_adjustment, annualization, price_basis, denominator` | 同比、环比、累计同比、季环比年化不能只用“%”区分 |
| 状态 | `actual / preliminary / revised / official_estimate / forecast / assumption` | 发布机构预测不等于已发生事实；衍生值另设标记 |
| 版本证据 | `source_id, source_locator, source_version, release_evidence, vintage_status` | 原件/返回及定位追溯到 invest-sources；无证明记 `unproven` |
| 原始取得 | `provider, provider_code, query_parameters, retrieved_at, artifact_hash` | 供应商代码到实际实施再核验；本轮不填猜测代码 |
| 缺失质量 | `missing_reason, coverage, age, break_flag, revision_size, quality_note` | `not_released / discontinued / not_applicable / retrieval_failed / unknown` 区分；零是有效观察，不是空值 |
| 派生依赖 | `input_refs, formula, lag, window, fit_cutoff, transform_parameters` | 所有标准化、去极值、季调和降维参数都只能由训练期估计 |
| 用途 | `decision_use, horizon, model_role, transmission_target` | 是解释、预测、风险还是约束；同一变量跨用途可有不同变换 |

“可获取”不等于“已采用”。目录按 `defined → source_mapped → vintage_checked → economically_reviewed → admitted_to_model` 记录状态；这些是简短状态字段，不另建审批系统。原始层保留缺失；模型层的填补值必须带填补方法和标记。

## 4 必须预先固定的变换规则

| 情况 | 处理方法 | 不能做什么 |
| --- | --- | --- |
| 流量累计值 | 在同一统计定义和版本下作差得到当期量，跨年单独处理；同比需用对应上年当期量 | 不能直接差分“累计同比”得到当月同比 |
| 中国 1—2 月合并 | 保留双月观察期，模型允许缺口或以双月约束估计；估计单月另标 | 不能伪造 1 月数据或把两个月平均当官方值 |
| 季度 GDP | 原始季度频率；混频模型使用发布日；同比、季调环比和年化明确区分 | 不能线性插值成已知的月度 GDP |
| 春节和工作日 | 官方季调优先；自建调整仅作研究特征，保留节假日窗口与拟合截点 | 不能用全样本季调结果冒充历史实时信号 |
| 日频到月频 | 环境用时间加权/交易日均值，时点估值用月末，冲击用窗口变动；各自独立特征 | 不能全体系只用月均或月末；部分月份必须带覆盖比例 |
| 价格与总收益 | 股票含适用分红与公司行动；债券含票息；期货明确价格/超额/总收益 | 不能对不同回报定义直接估计配置矩阵 |
| 跨国可比 | 统一变换后再比较，保留各国定义差异；水平不可比可使用本国标准化趋势 | 美国 GDP 季环比年化不直接对比中国 GDP 同比 |
| 真实增长与通胀 | 名义额转实际额匹配合适平减指数，并标近似性质 | 不能把 CPI 当所有行业收入与投资的通用平减指数 |
| 制度与口径断点 | 前后分段或经官方桥接；模型加断点标记并检验稳定性 | 不机械拼接 M1、社融、统计行业分类与指数修订历史 |
| 数据过时 | 按预定发布时间、正常频率和异常延迟标记 freshness | 季度指标不能因不是当天更新就判坏数据；停更指标不能无限前填 |
| 短历史资产 | 用经济因子映射、压力情景或研究池管理，报告参数不确定性 | 不因全池共同样本不足而删除长期核心历史；不靠代理拼接制造 20 年实绩 |

## 5 预期差和市场定价的时间契约

每条预期差绑定同一发布事件、指标定义、观察期和调查截点：

`surprise = 首次发布值 − 发布前已冻结的调查中位数`

标准化分母使用该指标此前可见的预测误差尺度，不能用未来误差；若样本短或尺度近零，只保留原单位预期差。调查的样本数量、分布、机构范围与最近更新时间必须保存。调查均值与中位数可分别留存，不临时挑更能解释市场的一个。

“本期首次发布相对预期”“上期值本次被修订”“未来预测被上调”是三个不同信号。同次发布同时改变多个数字，市场反应不能自动归因给其中一个。若没有历史调查版本，只能分析观察值变化，不能给它起名“超预期”。

模型隐含预期同样要留模型与参数版本。例如远期利率包含风险溢价，盈亏平衡通胀包含通胀风险及流动性影响；不得把市场价格反推数无条件视为市场一致预测。预期差进入中期模型前，必须检验在定价、估值和成本之后是否仍有增量信息。

## 6 全球汇总与资产权重的区别

全球宏观摘要、投资组合和公司收入暴露分别使用不同权重：

- 世界实体增长：同时展示按购买力平价 GDP 和市场汇率 GDP 加权的视角；明确使用的历史权重版本。
- 全球上市股票：依研究目的采用可投资市值权重或明确政策权重，不能用 GDP 权重假装成市场组合。
- 行业需求：按目标产品地区需求量/价值权重；公司暴露：按实际收入、成本、产能和融资币种映射。
- 国际债券：发行币种、发行主体、信用与久期各自记录；债务存量大不意味着应该自动配置更多。

IMF 的全球增长聚合本身就区分 PPP 与市场汇率权重；其历史数据和成员范围也可能随版本修订。该定义支持分开维护宏观聚合与资产权重，不给投资权重提供最优性依据。[IMF WEO 方法问答](https://www.imf.org/en/Publications/WEO/frequently-asked-questions)。

## 7 收益和风险快照的共同口径

人民币主组合和美元美国组合分别冻结以下条件。美元只是美股的报价币种时，不改变人民币主组合的计价；资产进入哪个组合决定其评估口径。

| 项目 | 必须固定 |
| --- | --- |
| 回报 | 简单收益用于持仓加权，复合收益用于多期净值；对数收益仅在相应统计模型内使用 |
| 币种 | 本币、USD、CNY 与换汇汇率时间；CNY/CNH 区别；有无对冲及对冲比例 |
| 无风险基准 | 与计价币种、持有期间匹配的可实现现金总收益；预期收益可用同期短端路径假设；公司 DCF 另按期限采用 |
| 费用 | 管理/交易/市场冲击/税费、买卖价差、借券与融资、对冲成本，按账户和工具单独列 |
| 基准 | gross/net total return、股息税假设、成分版本、真实发布历史/回算历史、再平衡及停牌处理 |
| 估值时点 | 全球统一 UTC 截点及各市场最新可交易价；陈旧报价标记；非同步交易敏感性 |
| 私募估值 | NAV 的估值日与公布日、现金流、承诺未缴、退出限制；现金流不伪装成日频收益 |
| 现金与担保品 | 现金持仓、抵押现金、可用流动性、保证金占用分别记账；不重复计入期货总收益的利息 |

按共同有效样本估计一个小型核心矩阵可以作为基线，但不能用一项短历史卫星资产把全体样本切成极短窗口。扩大维度时采用因子结构或经过验证的缺失数据估计；逐对不同样本的相关系数拼出的矩阵未必半正定，必须检查并说明修正。

## 8 后续验证设计

本节只定义以后如何测试；不存在本轮回测结果。具体统计门槛在确定资产数、样本和决策约束后冻结，不能看完结果再挑标准。

| 层级 | 核心问题 | 证据与对照 | 失败处理 |
| --- | --- | --- | --- |
| 数据 | 是否拿到了当时可知且同口径的值 | 首次发布/修订/断点/未发布/节假日/跨时区真实样本；与原件定位核对 | 修复或排除受影响特征；不把采集失败当零 |
| 宏观状态 | 是否比简单模型更准确且稳定 | 与历史均值、随机游走或简单自回归对照；留出期误差、概率校准、拐点延迟；实时 vs 修订数据并列 | 降为解释指标，保留基准模型 |
| CMA | 收益假设是否有清楚来源和范围 | 收益拆分可加总/复算；参数敏感性；期限相同的历史实现分布；机构假设只作外部对照 | 扩大区间、降低集中度；不按历史最优权重反调假设 |
| 风险 | 协方差与尾险是否稳定 | 留出期波动误差、VaR/ES 覆盖与条件表现、相关性翻转、危机和流动性压力 | 使用更保守风险预算及压力覆盖；不删除最差时期 |
| 配置 | 增益能否覆盖复杂度与成本 | 同资产池、同币种、同成本的静态组合/简单风险预算基线；滚动训练，真实可交易滞后 | 不启用中期偏离，继续战略组合 |
| 实施 | 理论结果能否转换为可交易持仓 | 可交易工具、追踪偏差、最小单位、换汇/税/结算/保证金、容量与现金流 | 保留理论分析；受限工具不得自动换成不同风险的代理 |

验证统一使用时间向前滚动的训练—验证—测试顺序；变换选择、超参数、资产筛选均在训练部分内完成。对重叠的未来收益标签隔离训练和测试区间，避免同一未来区段被重复使用；长期 5—10 年实现值的独立样本很少，因此不能靠月度滚动窗口数量宣称大量独立验证。

所有尝试过的主要信号和模型都记录，防止只展示赢家。报告至少包含净费后回报、波动、最大回撤及恢复期、尾损失、换手、集中度、币种/因子风险、流动性和相对基准的差异；不把单一 Sharpe 作为接受标准。风险预测失效、信号失效和执行成本失效分别诊断。

## 9 最小可审阅结果包

实施后的每次配置版本至少交付：截止时间、资产与币种边界、数据/方法版本、核心假设和区间、基准与约束、候选组合及压力结果、改动理由、反证与缺口。每个动作都能追到具体证据或显式假设。

首次验证先选一个人民币小型流动资产组合及一个美元小型组合，验证收益口径和现金账，再逐步增加资产；不先建设庞大平台。数据质量通过、模型作者自检通过、研究可用、用户接受与实际实施分别记录。
