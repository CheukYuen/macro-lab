## 用户已定（2026-10-14，开始前四问，均选推荐项）

1. **用途**：两者共用底层。一套指标库与宏观状态判断，接两个出口：① 估值链路（Rf、ERP、行业需求与成本 → 公司参数）；② 大类资产配置（各资产预期收益、风险、相关性）。
2. **地域视角**：中美双核 + 全球因子。中国、美国各建完整指标与资产体系；欧日、新兴市场只取少数全球驱动；人民币、美元两种计价各算一套。
3. **时间尺度**：长短两层都要。长期（5–10 年）做资本市场假设，供估值终值与战略配置；中短期（1–12 个月）做周期定位与情景，供 2026–2030 展望与战术判断。
4. **数据源**：四类全部可用，即 Wind／Choice 全量 EDB、Bloomberg／LSEG 等终端、官方 API 与网络、一致预期与高频另类数据。
