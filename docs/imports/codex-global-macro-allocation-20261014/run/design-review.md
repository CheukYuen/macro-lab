## 1. 资产上限需要明确穿透计入规则

**定位：** `docs/designs/global-macro-allocation/03-模型与组合方案.md` 第 315—319、327、329 行（§8）；对照 `02-资产分类与基准.md` 第 51—61、159、174、182—186 行，以及 README 第 101 行。

**问题：** 四模板限制的是“股票资本权重”和“高收益／高风险信用”，同时允许私募、上市实物资产及另行接受的 funded 策略，但未定义这些持仓如何计入上述上限。“高风险信用需在资产目录定义”目前是待办，资产目录尚未给出计入集合或判定规则。02 已要求保留底层 beta 和穿透账，仍未把穿透结果连接到 03 的硬约束。

**影响：** 同一股权或信用风险可能因载体换名而绕过限制。例如 B 模板的上市股票与 PE 若只分别检查股票上限、非流动上限，组合总股权风险可能超过读者对该模板的理解；上市 REITs 和股票多空 funded sleeve 也可能被漏计。反过来，若作者本意只限制上市股票，就必须另列总股权风险限制或明确其暂不受该项限制，不能让不同实施者自行解释。这会改变可行域、候选权重和压力损失。

**最小修正：** 在 §8 绑定一张约束计入映射：每项限制的对象、分母、穿透规则、资本权重或经济／风险暴露口径，以及资料不足时的处理。明确 PE、上市 REITs／基础设施、私募债和 funded 策略的归属；明确高风险信用的筛选或裁定条件。无需现在选正式阈值或计算 beta，不能可靠分类的卫星先不获准进入相应受约束组合。

## 2. 真实系统历史重放的可用时间必须早于决策冻结

**定位：** `docs/designs/global-macro-allocation/04-数据口径与验证设计.md` 第 33—39 行（§2.2）；对照 `03-模型与组合方案.md` 第 351—353、361—363、370 行。

**问题：** 04 正确要求公开版本早于 `decision_at`，但对“模拟真实系统执行”额外只要求渠道可见时间及处理延迟早于 `earliest_execution_at`。这不足以证明输入在决策冻结时已进入该系统。例如官方发布在冻结前，渠道在冻结后才提供值，而成交更晚，现有条件仍可能允许用该值生成已冻结决策。

**影响：** 公开信息可得性重建可能被升级为真实系统历史重放，掩盖入站延迟，并让历史信号比系统当时实际可产生的信号更及时；这会影响 PIT 标识、成交时点及中期模型验证结论。

**最小修正：** 将两种实验分开：公开信息重建按可证公开时间与明确的保守处理假设取快照；真实系统重放还要求可证系统入站／可用时间加处理延迟不晚于 `decision_at`。晚到值只能进入后续决策，或将该次决策冻结时点相应后移，再确定允许成交时间。今天补下载的旧版本不得补作系统历史入站证据；缺历史入站记录时保留重建身份。

- 长期几何 CMA、算术均值、累计持有期收益及再平衡路径已有区分；03 的配置与主动风险要求共同期限，未发现必须另报的期限算术错误。长期 CMA 到短期分布的具体路径仍是明确列出的实施未决项，不把其未校准视为本轮设计失败。

- 现金、商品 ER／TR、担保品和 overlay 已明确二选一账法，未发现重复利息规则错误。
- 全球父股票宇宙、地区叶槽、A/H／ADR、商品与黄金及上市／私募暴露已有边界；实际成份交集、指数许可、税费、渠道、风险参数和性能均未验证。
