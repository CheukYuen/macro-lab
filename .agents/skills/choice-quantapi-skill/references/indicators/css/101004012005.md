|参数编号|英文简称|中文说明|取值范围|默认值|
|---|---|---|---|---|
|1|ReportDate|报告期||获取规则：去年年报|

|3|DataType|数据类别|1 期末余额<br>2 本期增加额<br>3 本期减少额|1|
|4|ItemsCode|科目||1|
