|1|ClauseType|条款类型|11 定向转让<br>12 票面利率<br>2 回售<br>3 赎回<br>4 可调换<br>8 提前偿还<br>21 其他<br>22 全部|2|
|2|Times|N天||1|
|3|ClauseType|条款类型|1 回售<br>2 赎回|1|
|4|EndDate|截止日期||获取规则：最新日期|
