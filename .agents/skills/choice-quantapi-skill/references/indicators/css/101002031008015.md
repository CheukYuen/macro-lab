|中文简称|英文简称|参数1|参数2|单位|精度|释义|

|全部投入资本|INVCAP|报告期[1]|币种[2]|元|0.0000|参见算法<!-- 目录：股票 / 港股及美股指标 / 财务分析 / 衍生指标 / 基于资产负债表 -->|
|营运资本|WCAP|报告期[1]|币种[2]|元|0.0000|营运资金是指流动资产减去流动负债后的余额，是按照账面价值将流动性资产转换成现金清偿全部流动性负债后，剩余的货币量。营运资金越多，意味着企业偿还短期债务的可能性越大。<!-- 目录：股票 / 港股及美股指标 / 财务分析 / 衍生指标 / 基于资产负债表 -->|

|有形资产|TANASSET|报告期[1]|币种[3]|元|0.0000|有形资产净值，简称有形净值，是股东权益(不含少数股东权益)减去无形资产净值（包含：无形资产、商誉、开发支出、长期待摊费用、递延所得税资产）后的实物资产账面价值。<!-- 目录：股票 / 港股及美股指标 / 财务分析 / 衍生指标 / 基于资产负债表 -->|
|带息债务|INTDEBT|报告期[1]|币种[2]|元|0.0000|有偿使用的债务资本。<!-- 目录：股票 / 港股及美股指标 / 财务分析 / 衍生指标 / 基于资产负债表 -->|
|无息流动负债|NONINTLL|报告期[1]|币种[2]|元|0.0000|无息流动负债在资产负债表中主要表现为应付账款、应付工资、其他应付等。无息流动负债也是企业对其他方资金的一种占用，但这部分资金并不来自于投资人，这种资金占用只是企业正常经营活动中的一个必要环节，一种循环占用。<!-- 目录：股票 / 港股及美股指标 / 财务分析 / 衍生指标 / 基于资产负债表 -->|
