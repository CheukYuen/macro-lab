# 07 迁移到估值链路

原项目服务大类资产配置与月报，终点是「资产方向」；invest-lab 的终点是「行业需求／价格 → 公司收入、毛利率、再投资、折现参数」。以下只给对照与建议，采用与否由宏观层作者按 `SPEC.md` 决定。

## 1. 可直接复用

| 内容 | 出处 | 复用方式 |
| --- | --- | --- |
| 指标挑选五原则 | `01` §1 | 宏观层选指标、写「未纳入维度理由」时的判据；第 5 条传导终点改为公司参数 |
| 四模块（增长→方向、通胀→利率、流动性→估值、需求结构→行业） | `01` §2.2 | 宏观交接包的分析骨架；每模块输出状态、趋势、驱动、影响 |
| 口径规则（月均 vs 月末、累计值派生、NULL 不填 0、修订不覆盖） | `01` §4 | 驱动记录的口径说明 |
| 长表喂数格式 + 定义层口径 | `03` §4 | LLM 角色读取宏观数据时的输入格式 |
| 逆向工程提问序列 | `03` §1 | 设计角色提示词、反推行业／公司研究所需数据 |
| 硬事件／原子事件规则 | `04` | 政策与贸易维度的事件输入；需扩展到行业、公司层级 |
| 生成—评测—优化骨架 | `03` §5 | SPEC 规定首轮不建评估系统；流程跑通后从真实错误中做最小评估时可参考 |
| 股债负相关、期限利差与信用利差历史区间 | `02` §4 | 背景参照，不作估值输入 |

不复用：历史均值 μ、以 1Y 为折现无风险利率、原库表与 ETL 实现、附录数值（截点未证实）。

## 2. 与 invest-lab 宏观六维度对照

| invest-lab 维度 | landing-zone 已有 | 缺口 |
| --- | --- | --- |
| 增长与需求 | GDP、PMI、工业增加值、投资三分法、社零、进出口、新出口订单 | 设备购置投资、企业资本开支细分；通信与数据中心相关产出 |
| 资本开支 | **无** | 云厂商、运营商 Capex 是首轮主线，landing-zone 完全没有覆盖 |
| 利率与流动性 | 国债 1Y／3Y／10Y、DR007、LPR、M1／M2／社融、AA 企业债收益率 | 实际利率（10Y 减通胀预期或 TIPS）、美债利率、ERP |
| 汇率 | 美元兑人民币中间价（月均） | 截点日即期汇率；A／H 估值所需港币汇率 |
| 通胀与成本 | CPI、PPI、布油、南华商品、黄金 | 行业原材料与能源价格（按公司成本结构选取） |
| 政策与贸易 | 新闻原子事件规范，无结构化数据 | 关税、反倾销、通信建设政策的结构化事件记录 |

## 3. 估值衔接要点

1. **折现率**：宏观层提供利率环境与情景，公司层负责期限／币种匹配与 ERP 采用（SPEC 规定）。landing-zone 的 1Y rf 只用于短期绩效，不带入 DCF。
2. **情景**：四模块的状态判断可以作为 `capex_up／base／capex_down` 情景下的宏观环境描述，但不机械同向；利率、汇率、成本可在情景间保持不变或按依据变化。
3. **驱动记录**：landing-zone 长表只有 `indicator_id, ref_month, value, unit, adjustment, source`；进入 `drivers.json` 还需补性质（实绩／指引／机构预测／假设）、来源定位、发布日期与版本依据、缺口。
4. **传导**：

```text
增长  → 行业需求量、开工率
通胀  → 原材料成本、售价传导 → 毛利率
流动性 → 无风险利率、信用利差 → 折现率、估值倍数
需求结构 → 哪些下游、哪些地区在贡献或拖累 → 行业需求池拆分
```

5. **新闻**：放开「排除个股／单行业」，按宏观／行业／公司三级打 `event_type`，事件必须带来源与发布时间，否则不能通过截点检查。

## 4. 中美扩展

原银行指标清单已有 24 项美国宏观指标，但没有代码与口径：

- 增长：GDP（季环比年化）、零售销售、耐用品订单、实际消费、居民可支配收入。
- 地产：成屋／新屋销售量与价格，新屋开工／施工／竣工。
- 就业：失业率、劳动参与率、非农新增、薪资、ADP、初请与续请失业金。
- 景气：ISM 制造业、ISM 服务业、Markit PMI、消费者信心。
- 通胀：CPI、核心 CPI、PCE、核心 PCE、PPI、核心 PPI。

做美股或海外收入暴露的估值，还需补：

- 政策利率与曲线：联邦基金目标区间、美债 2Y／10Y、10Y TIPS 实际利率、10Y 盈亏平衡通胀。
- 金融条件：美元指数、投资级与高收益信用利差、VIX。
- 估值锚：标普500 前瞻 PE、ERP。
- 中美联动：中美 10Y 利差、美元兑人民币即期与远期。

按五原则，每个信息维度只留一个锚点（如就业首选非农与失业率，通胀首选核心 PCE），避免把 24 项全部喂给模型。

## 5. 建议的使用顺序

1. 宏观层作者先读 `01` §1–2 与 `06`，确定本次研究按公司暴露需要的维度。
2. 需要的序列按 SPEC 渠道顺序（Wind → Choice → 官方）重新取数并登记版本；`01` 指标字典中的 Choice ID 只作查找线索。
3. 若用 LLM 读宏观数据，沿用 `03` §4 的长表格式，并把衍生利差、断点说明写进定义层。
4. 流程跑通、出现真实错误后，再参考 `03` §5 建最小评估。
