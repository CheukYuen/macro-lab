# 全球宏观与大类资产配置：宏观指标体系详细设计

状态：**proposed，供审阅**。设计日期：2026-10-14。范围：全球覆盖、中美重点；主组合以人民币计价，美国组合以美元计价；长期配置为主，同时支持中期判断和日常风险监测。本文件只设计指标、口径和研究接口，没有金融数据取数、计算、编程或回测，也不构成当下宏观判断。

本设计服从 [SPEC.md](../../../SPEC.md)。它是新配置研究的候选设计，不修改现行长飞研究的范围、信息截点和 `capex_up/base/capex_down` 情景键。旧 [宏观指标萃取](../../imports/landing-zone-macro/01-宏观指标体系.md) 与 [问题清单](../../imports/landing-zone-macro/06-问题清单.md) 提供结构和已知错误线索；其附录数字、供应商代码、历史相关性和未验证效果不迁入本设计。

## 1. 决策目标与分层

指标体系要回答三个不同问题：经济与政策怎样变化，市场已经反映了多少，以及组合承受哪些风险。例如，增长改善可支持企业盈利，但若估值已经隐含更强增长、融资成本同时上升，就不能仅据 PMI 回升推导股票应加仓。三层证据需要并列观察，研究结论还需经过资产收益、风险和实施约束的接口。

| 层 | 内容 | 主用途 | 明确边界 |
| --- | --- | --- | --- |
| E：经济事实与制度 | 产出、需求、通胀、劳动力、信用、财政、国际收支、产业投资和制度事件 | 描述经济状态、结构变化、约束及传导假设 | 不把好经济机械映射为好收益；统计实绩、官方预测和研究估计分开 |
| P：预期与价格/估值 | 调查预期、市场隐含路径、预期差、预测修订、估值和风险溢价代理 | 比较研究判断与已定价条件；构建收益观点的证据 | 市场隐含量含风险溢价；调查不等于市场共识；估值水平不直接变成择时信号 |
| R：风险与市场运行 | 波动、相关性、回撤、信用压力、融资/交易流动性、集中度、政策风险 | 组合风险复核、压力情景、事件升级 | 风险升高不等于自动卖出；不同币种、市场时间和风险期限不能混用 |

每个条目另标研究优先级：**核**为常规研究应检查的核心项；**诊**为解释冲突、排除替代机制的诊断项；**专**为按暴露开启的专题项。优先级不等于入模资格。本文件全部 85 个条目/有限指标组属于研究池；没有任何条目已经获准自动进入模型。

| 资格 | 判断问题 | 候选用途 | 升级条件 |
| --- | --- | --- | --- |
| 研究池 | 有经济含义、可定位原始来源、与暴露有关吗？ | 人工研究、反证、事件记录 | 明确口径、可用时间、限制和缺口 |
| 状态特征候选 | 能在当时可知信息下稳定描述状态吗？ | 增长/通胀/融资状态及情景解释 | 实际来源验证、版本可得性、缺失策略、冗余检查、样本外验证方案 |
| 收益观点候选 | 对预期收益有传导依据，并知道市场已定价什么吗？ | 长期收益积木或有期限的配置观点 | 绑定资产和期限、解释因果与替代机制、确定观点置信度及失效条件 |
| 风险输入候选 | 是可比的价格、收益、暴露或风险统计吗？ | 风险估计、压力映射、约束监测 | 与资产建模合同的币种、频率、总收益、样本与估计方法一致 |
| 事件/限制 | 不能稳定数值化但会改变资格或传导吗？ | 情景条件、人工复核、实施限制 | 留原始文件、发布/生效/过渡日期与影响对象；不强造分数 |

同一经济维度可保留互补指标：GDP 是总量锚，PMI 是调查扩散，工业生产是实现量；失业率、参与率和工时共同区分需求与供给。入模时检查重叠贡献、共线性和共同来源，不机械“每维度只留一个”。长历史优先，但不设无条件二十年门槛；制度改变后的短序列可以做专题或事件研究，不能凭短历史估计稳定长期风险参数。

### 三种观察时钟

| 时钟 | 观察与复核 | 主要证据 | 行动接口 |
| --- | --- | --- | --- |
| 长期结构 | 年度/季度复核，遇重大制度变化重审 | 潜在增长、人口/生产率、财政可持续性、储蓄与国际收支、投资结构、估值 | 长期收益区间、战略资产假设；不按单月数据重设 |
| 中期周期 | 月度复核，统计发布时更新事实 | 增长动量、通胀粘性、信用/财政冲量、政策和预期修订 | 有期限、有反证的观点及情景；传导滞后按对象说明 |
| 日常风险 | 日/周监测，按事件升级 | 利率/汇率跳变、波动、信用/融资压力、市场流动性、发布日历 | 风险复核请求与约束检查；具体触发阈值由风险方案另定 |

## 2. 字典规则

下表按主题列出 **85 个主条目/指标组，不是 85 条可直接建模序列**。`ind.<region>.<theme>.<meaning>` 是本项目稳定逻辑 ID，**不是供应商代码**。`cn/us/gl` 表示中国/美国/全球，`geo` 表示按国家实例化的通用定义。有限指标组的成员在定义列明确列出；实施时按地区、成员、期限和口径展开独立 `series_id`，另建元数据与观测版本；不同用途变换另建 `feature_id`。例如曲线组展开中国十年中债曲线与美国十年财政部平价曲线，各有自身定义/版本，不把二者或不同单位装入同一个数值字段。对象、币种、季调方式和方法版本同时是键的一部分，ID 不靠改名隐含口径切换。具体字段遵循 [数据口径与验证设计](04-数据口径与验证设计.md)，下游采用遵循 [研究接口与实施顺序](05-研究接口与实施顺序.md)。

频率为候选原始频率：D 日、W 周、M 月、Q 季、A 年、Ev 事件。按本轮设计假定实际数据供应可获取，不以采购覆盖压缩研究池；历史 vintage、精确可知时点、成员定义和持续性仍须另验。表内“原始机构”仅表示未来定位的编制/发布主体，不表示接口或历史版本已验证。正式数值查询遵循 SPEC 渠道顺序和执行授权；浏览一手方法页面不等于数据渠道验收。表内用途均为待研究的机制，不是已验证交易效果。

所有组还需记录：成员清单、地区/行业/主体、单位与币种、实绩/指引/预测/估计性质、统计期间、发布时间与时区、版本可知时间、季调/年化/价格基础、候选转换、来源定位、缺口、研究优先级及入模状态。原始观察保留，派生另登记依赖 ID 和方法版本。

## 4. 派生与同口径规则

以下均为公式设计，未执行。符号 `v|c` 指截至研究截点 `c` 实际可知的版本，不指事后最新值；原始单位统一后再派生。百分点与基点单独标记，不把百分数与小数相减。

### 4.1 发布、修订、频率与标准化

| 操作 | 设计口径 | 失败/限制处理 |
| --- | --- | --- |
| 截点快照 | 取发布时间/版本可知时间 ≤ 截点的值；观察期和可用日期分开 | 仅知取得日不能证明历史可知；无版本则限制为当前描述，不进 PIT 验证 |
| 美国 GDP 年化换算 | 非年化环比 = `(1 + 年化率/100)^(1/4) − 1`；同比另用同版量指数 | 不将 SAAR 金额再乘四作全年实绩；同比不用环比年化代替 |
| 同比/动量 | 量/价指数同比 = `X_t/X_(t−12)−1`；季度为四季。若要年化多月动量，注明季调序列、窗口和幂次 | 没有季调不声称剔除季节性；疫情/春节等基数另解释 |
| 累计转当期 | 同一披露版和同一统计边界的累计金额 `C_t−C_(t−1)`；跨年重置，一二月合并整体保留 | 不能把累计同比直接相减算当月同比；只有增速则保留原口径 |
| 日转月 | 环境量用已结束月的有效交易日均值；投资起点/风险观察用最后有效报价；高频量保持原频率 | 部分月份单列截止日/覆盖；末值过旧标 stale，不无期限前填 |
| 年/季到月 | 保存上次已发布值及 age，不制造中间观测；事件保留日期 | 是否供状态模型沿用由特征合同决定；不得把前填当新增信息 |
| 指数/总收益 | 宏观价格观察与资产收益原件分开；风险/收益接口采用资产合同确定的总收益和对冲状态 | 连续商品报价、VIX 水平、国债收益率均不能直接当资产总收益 |
| 滚动标准化 | 按截点前同定义样本估计均值/尺度或分位；窗口、季节处理、极值规则由特征版本冻结 | 无全样本均值/未来趋势泄漏；短样本/零尺度则停该特征，保留原值 |
| 断点 | 单独记录统计、制度、市场微观结构和供应商映射断点；官方可比回溯/重叠桥接有依据才连接 | 不能凭水平接近或模型拟合直接拼线；结构变化可改用事件/分段特征 |

历史需求以使用目的决定：长期增长/估值研究尽量覆盖多个周期；风险估计使用资产方法批准的共同有效样本；高频/新制度观察允许较短历史但收窄结论。每项记录可得起点、连续段、历史 vintage 起点、独立有效样本和用途限制，不能把“有二十年最新修订值”当作“有二十年当时版本”。

### 4.2 增长、价格与曲线

1. 名义/实际 GDP 的隐含价格同比优先用官方平减指数。若同版名义、实际增长率可比，派生 `π_deflator=(1+g_nominal)/(1+g_real)−1`；名义/实际水平比只在实际量的基准/计价定义可比时使用。链式分项加总使用官方贡献而不硬加链式金额。
2. 期限利差为同日、同币种、同编制曲线 `y_long−y_short`。信用曲线差采用同期限/评级/债种，保留回收率、税务、期权和流动性限制；与 OAS 分 ID，不称纯违约补偿。
3. 事前实际率代理为同期限名义率减对应期限年均通胀预期。精确 Fisher 关系可另作敏感性定义 `(1+i)/(1+π_expected)−1`，不能混用两种口径。若期限不匹配，只交“不匹配的方向诊断”。名义率减过去同比通胀另命名事后代理。
4. `BE_n=y_nominal,n−y_TIPS,n` 仅是同期限曲线通胀补偿近似。远期通胀补偿若缺同基础零息曲线，则不硬算 `5y5y`；平价差、零息差、调查预期各自保留，研究不强行去除无法识别的风险溢价。

### 4.3 信用冲量

本设计选择**同比变化的滚动融资流量占 GDP 比重**作为一种候选定义，不声称它是唯一“信用冲量”。季度版本：

- `NC_q`：同口径当季净新增融资流量；优先官方流量，若只得存量，派生差额必须剔除/声明汇率、核销、重分类和估值调整。
- `F_q = Σ_(j=0..3) NC_(q−j)`；`Y_q = Σ_(j=0..3) nominal_GDP_(q−j)`，均为同币种、同可知 vintage。
- `CI_q = 100 × [F_q/Y_q − F_(q−4)/Y_(q−4)]`：金额比先为小数，乘 100 后输出 GDP 占比变化的百分点；同比滞后四季用于观察融资流量强度的变化。
- 若展示季差 `100 × [F_q/Y_q−F_(q−1)/Y_(q−1)]`，另命名季度变化，单位同为百分点，不能与同比版本拼接。月版可用滚动十二月融资，但只在名义 GDP 季度可知值的月分母处理被批准后使用；不线性插值未来 GDP。

中国至少区分全社融与剔政府融资的私人融资代理；美国按非金融私人部门金融账户定义，社融和美国口径不直接比较绝对水平。不把借新还旧、债券置换全算新增需求；融资供给、借款意愿和项目落地由组成、SLOOS/调查及 Capex 交叉判断。融资到需求的滞后因地区、部门和制度而异，未来验证后登记，不在设计阶段默认固定领先期。

### 4.4 财政冲量与代理

正式候选：若 `capb` 是比例小数，`FI_t = −100 × (capb_t − capb_(t−1))`；若原始 `capb` 已为百分数，直接取负差，不再乘 100。`capb` 必须为**同一机构、方法版本、广义政府边界**的周期调整初级余额占潜在 GDP 的比例，输出为百分点；正值表示该测度上的财政扩张。初级余额剔净利息，潜在产出/收入弹性和一次性因素处理留方法记录。指标不是财政乘数，也不能单独证明 GDP 增长贡献；季度值仅在采用机构有可验证季度估计时使用，不能拆年度 CAPB 造季度数据。

中国现金代理：同一边界 `D_q=rolling_4Q(cash_expenditure−cash_revenue)`，`CP_q=D_q/rolling_4Q(nominal_GDP)` 为比例小数，`cash_impulse_proxy_q=100 × [CP_q−CP_(q−4)]` 输出 GDP 占比变化的百分点。一般公共预算与政府性基金先分别算；只有转移、调入、结转、土地收入和融资处理有完整去重桥接，才建立另一个广义边界版本。缺利息分项则标非初级；缺周期调整则标非 CAPB。土地出让下降造成的现金缺口扩大，不能直接解释为新增财政需求刺激。

债券发行进度为同口径年内新增发行/截点前有效年度额度；额度后来调整要另版本，不能用年底额度回写年初分母。再融资发行另列，发行、拨付与项目支出不能合并成同一“进度”。

### 4.5 预期差、修订、美元融资及估值

| 特征 | 设计定义 | 必须保持的边界 |
| --- | --- | --- |
| 发布预期差 | `S_t=actual_first_release_t−median_expectation_(t,freeze)`，冻结时点早于发布；两者必须同期间/单位/季调/年化 | 有调查样本数、离散度和截止时间；没有真实预期数据时不从后来报道反推 |
| 标准化预期差 | `ZS_t=S_t/σ(S_prior)`；尺度只用此前同定义发布误差，窗口与最小样本待批准 | 正号仅表示高于预期，不自动表示对资产利好；通胀/失业可有相反传导 |
| 修订新闻 | `revision_(ref)=value_(next_release,ref)−value_(first,ref)`；另列预测 `forecast_(new,h)−forecast_(old,h)` | 相同观察期/预测目标 `h`；基准重估与常规修订分别标记 |
| 组合币种转换 | 以“单位外币可换多少基准币”为 `FX`，未对冲收益满足 `(1+r_local)×(FX_t/FX_(t−1))−1` | 本币、人民币、美元和已对冲序列分别登记；汇率时间与资产合同对齐 |
| 对冲成本 | 同币对、期限、结算/抵押及日计数的实际远期/互换条款，保留点差/展期/费用 | 利差只作近似解释；远期点不等于汇率预期，不能忽略基差 |
| 风险溢价代理 | `earnings_yield−government_yield`；现金流隐含 ERP 则完整登记增长/分红/回购/终值/折现假设 | 代理与估计分开；不把股票 PE 倒数减国债利率直接填公司 ERP |

调查预测修订、统计实绩修订和市场隐含路径变化三者分开。需要合成预期差指数时，必须先确定成员、权重、发布时点、方向、尺度和缺失成员规则；本轮不设默认权重、不建立一个综合“利好分”。

## 5. 研究输出、资产接口与行业公司接口

每次研究按地区和主题交付下列内容，不要求把全池原始观测一次性交给模型：

| 输出 | 最小内容 | 用途与限制 |
| --- | --- | --- |
| 事实快照 | cutoff、统计观察期、可知版本、已发布/待发布/stale 状态、核心/诊断证据 | 呈现当时可知内容；不把空值写零或模型补值写事实 |
| 状态判断 | 水平、方向、变化广度、证据冲突、主要机制、替代解释和置信度依据 | 可用连续描述；阈值/状态机为未来特征合同，不由 LLM 临时造 |
| 定价对照 | 研究条件、调查/市场条件、差异和期限，风险溢价限制 | 形成配置观点候选；没有定价证据则只交经济判断 |
| 资产传导 | 指标→机制→资产收益/风险组成、方向条件、适用期限、失效证据 | 股/债/信用/现金/商品/黄金/地产等逐项解释；不由宏观分数直接生成权重 |
| 风险复核 | 价格/融资压力、相关性变化、集中/流动性风险、事件请求 | 与风险/实施约束对接；组合动作由批准方案决定 |
| 行业公司交接 | 已选驱动 ID/版本、地区/产品需求池、滞后、转换依据、缺口 | 宏观提供环境和投资方向；行业负责需求/供给/价格，公司负责经营/折现采用 |

常见传导需写条件：增长加强可能推升盈利和实际利率；供给型通胀可能压低利润并抬高债券贴现率；信用扩张要区分私人投资与政府再融资；实际利率下降对黄金机会成本的作用仍受美元和风险偏好影响。上述是研究机制候选，不能当固定相关性或已验证预测规律。

给资产模型的是按使用场景选取并经资格审查的**核心输入子集、确切 feature_id/版本、观察时点、滞后与用途**，不是 85 个 ID 的无条件全集。经济事实模型、收益观点和风险估计各自选特征，不把日频波动、季频 GDP 与政策事件揉成一个未经验证的总分。估值、信用价差、波动和金融条件指数可能共享同一市场价格或风险因子，先登记成分/依赖和重复信息，再评价增量贡献，不当作多份独立宏观证据投票。中美研究共用定义原则而不要求同方向情景；配置新情景另建命名空间，现行 Capex 情景只按 SPEC 引用。
