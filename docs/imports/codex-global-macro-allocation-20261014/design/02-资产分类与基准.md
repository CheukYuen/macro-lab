# 资产分类与基准：全球研究、双币种组合的详细设计

日期：2026-10-14。状态：**proposed／详细设计 B**，供用户审阅；尚未接受或实施。本文仅规定分类、候选基准与收益归属，不含数据采集、计算程序、回测、当前预期收益或建议权重。文中期限分桶和教学数字均为设计候选或纯假设，未校准。

适用目标：长期大类资产配置为主，兼顾中期与日常风险，并为宏观→行业→公司提供经济暴露字典。人民币全球主组合与美元美国组合分别建账。本文不修改 [SPEC.md](../../../SPEC.md)，不替换现行长飞 `capex_up/base/capex_down` 情景，也不授予正式研究或基线身份。后续实施仍遵守 SPEC 第 5 节及其引用的启动纪要顺序。

## 1. 本版决定与旧候选的处理

先回答“钱在承受什么风险”，再回答“用什么买”和“采用什么策略”。全球指数、基金类别与经济资产不能处于同一权重层。例如，配置全球股票后增配美股，会增加已有的美国暴露；买入美元计价中国 ADR，既不自动成为美国经济暴露，也不因为记账币种是美元而没有中国风险。

| 旧候选做法 | 本版决定 | 后果 |
| --- | --- | --- |
| 四条腿覆盖全部产品，黄金与商品按固定比例合成 | 黄金与非黄金商品分别研究；资产、策略和工具分层 | 不沿用无依据的黄金／商品权重 |
| 货币基金可投资债券指数代表现金 | 现金底层按实际短期资产、币种与滚动规则定义 | 有信用／久期的债券篮子不能当无风险现金 |
| 股票基金、多空基金、偏股基金混合代表股票 | 广义股票 beta 与主动、多空策略分开 | 策略净值不能替代股票市场基准 |
| ACWI、World、EM、美国、中国可并列 | 单一父宇宙的互斥区域槽；综合指数作汇总参考 | 同一证券不在基础资本预算中重复 |
| REITs 代替全部房地产，私募债用纯债代理 | 上市与私募分开；缺证时保留卫星研究状态 | 不用上市市场波动证明私募低风险 |
| 指数名称／供应商代码足够绑定 | 定义、收益、币种、税、套保、版本与估值时钟一起绑定 | 同名不同收益变体不互换 |

旧资料只沿用“收益序列与解释因子分开”“修订追加”的原则。[导入 README](../../imports/landing-zone-macro/README.md)及[问题清单](../../imports/landing-zone-macro/06-问题清单.md)中的候选数值、历史参数、渠道状态和附录均未采用。

## 2. 三层模型与覆盖状态

| 层 | 含义 | 例子 | 权重／评价规则 |
| --- | --- | --- | --- |
| 经济暴露层 | 谁的现金流或价格风险，附币种、期限、信用、流动性属性 | 美国股票、人民币国债、黄金、灾害保险风险 | 核心资本预算按互斥叶节点计；风险因子可以交叉，但不加成第二笔资本 |
| 实施工具层 | 法律权益、交易地点、载体、融资与托管 | 现券、ETF、基金、ADR、期货、掉期、私募有限合伙份额 | 同一暴露可映射多种工具；指数是计量规则，不是可以直接成交的工具 |
| 策略层 | 如何持有、选择、对冲和再平衡 | 市值加权、价值倾斜、股债混合、趋势、套利、外汇套保 | 每个策略绑定底层暴露和自有资金／衍生品资金账；不得靠策略名称改变经济归属 |

建议使用四种状态，避免“覆盖”被误读成“已可配置”：

- **核心候选**：经济定义和收益账可标准化，原则上可以进入液态资产模型；仍须通过基准与数据资格检查。
- **卫星候选**：与核心有重叠、非线性、较强经理选择或专门实施问题，单独研究；获准后再扩展模型。
- **现金流研究池**：非流动资产以资本调用、分配、NAV 与承诺管理为主，不直接加入月度液态协方差矩阵。
- **观察池**：定义、估值、连续性或可实施性不足；可研究，不默认赋予非零权重。

“未进入首个可建模集合”必须写原因，不能解释为无经济价值。核心候选也不表示未来样本、许可、报价或交易资格已验证。

## 3. 全球经济资产树

下表是可扩展的经济结构，不是产品采购清单。地区、币种、期限、信用为属性维度，不将其全部做笛卡尔积；每次选定的叶节点必须说明为什么需要独立资本槽。

| 经济分支 | 研究覆盖与关键拆分 | 默认状态及用途 |
| --- | --- | --- |
| 现金与短期融资 | CNY、USD 及按需要的其他币种；短国库券／国债、回购、存款、货币基金、短信用票据分别标信用与赎回条件 | 本币高质量短期资产为核心；外币现金承受 FX；基金、存款与信用票据为工具／信用扩展 |
| 名义主权债 | 中国、美国、其他发达市场、新兴市场；本币／硬通货；短、中、长久期；政策性与机构债另标担保性质 | 中国／美国期限桶核心；其他市场为全球扩展候选；新兴主权须附违约和资本流动风险 |
| 通胀挂钩债 | 美国 TIPS、其他国家通胀挂钩债；对应通胀指数、滞后、实际久期、到期保护条款 | TIPS 为核心候选，其他市场扩展；不存在可用中国同类基准时留空 |
| 公募信用债 | 投资级、高收益、贷款；发行人国家与发行币种分开；担保／优先级／固定或浮息；评级体系及迁移 | 中国与美元投资级核心候选；HY、浮息贷款为卫星或获准扩展 |
| 证券化与混合债性 | MBS／ABS／CMBS、可转债、永续／资本证券、地方债 | 卫星；分别考虑提前偿付、负凸性、股性、减记及税制，不强归入普通 IG |
| 上市股票 | 美国、中国、多地区发达市场、新兴市场、前沿市场；大中小盘、行业、风格及多上市地 | 互斥地区 broad beta 为核心；风格、行业和小盘是同一权益宇宙内的倾斜／扩展 |
| 上市房地产 | Equity REITs／物业公司；按地区、物业用途、租约、杠杆区分；Mortgage REITs 单列信用／融资结构 | 卫星；底层属于上市权益，专门基准需处理与 broad equity 的交集 |
| 上市基础设施 | 公用事业、交通、能源、通信等；经营模式、监管／特许权、资本开支与杠杆 | 卫星；受股票估值及经营现金流双重影响，不当固定收益替身 |
| 黄金 | 实物或现货定价的黄金；黄金期货为工具；金矿股为股票 | 独立核心候选；研究实际利率、货币及避险机制，不能预设稳定通胀对冲或固定正收益 |
| 非黄金商品 | 能源、工业金属、非黄金贵金属、农业／畜产品；现货机制与期货可投资收益分开 | 期货充分抵押篮子为核心候选；单品种、碳排放权为卫星或观察池 |
| 私募股权／创投 | Buyout、growth、VC、二级份额；按地区、年份组、行业与融资杠杆 | 现金流研究池；经理选择、退出、估值和未调用承诺主导 |
| 私募债 | 直接贷款、夹层、困境、特殊机会、资产融资；浮息、回收率、PIK、契约、杠杆 | 现金流研究池；不是“无波动债券”，上市信用仅可作经济因子参照 |
| 私募实物资产 | 直接房地产、私募基础设施、农地、林地；项目／基金层分别看杠杆和现金流 | 现金流研究池；估值频率与上市价格分开 |
| 保险相关风险 | Cat bonds、抵押再保险、寿险／长寿风险等 | 卫星／现金流研究池；灾害触发、模型、尾损、抵押和资金被困分别研究 |
| 数字资产 | 原生代币、稳定币、质押、数字资产期货；代币化证券按底层证券归属 | 观察池；价格、托管、协议、兑付、资金费率分开，稳定币不默认等于现金 |

对冲基金、CTA、全球宏观、市场中性、事件驱动、波动率策略、风险平价、固收+、股债混合均进入**策略研究池**，不作为上述树中可互斥的“第五类资产”。它们可以形成单独的 funded sleeve，但必须保留底层 beta、杠杆、尾部与流动性账。

## 4. 核心可建模槽及区域互斥

### 4.1 人民币全球主组合的候选叶节点

下面给出足够细的起始结构。未获合格收益序列的槽处于待建状态，不以代理填满矩阵；期限分桶为**待验证设计候选**，优先贴合指数商现有互斥区间，同时展示实际久期。集合大小不是优化目标。

| 槽 ID（设计标识） | 经济定义 | 必须明确的边界 |
| --- | --- | --- |
| `cash.cny` | 人民币短期高质量滚动现金 | 期限上限、主体、滚动及利息再投资；不等于 10Y 收益率 |
| `cash.usd` | 美元短期高质量滚动现金 | CNY 折算及套保政策；不得与 USD 债短期桶使用同一证券宇宙重复计资本 |
| `bond.cn.gov.short/mid/long` | 人民币名义国债互斥期限桶 | 候选 `(1,3]`、`(3,10]`、`>10` 年；小于等于 1 年由现金定义覆盖或明确空缺 |
| `bond.us.gov.short/mid/long` | 美元名义 Treasury 互斥期限桶 | 同样候选边界；随剩余期限变化的迁移与再平衡由方法定义 |
| `bond.us.ilb` | 美元通胀挂钩 Treasury | 实际久期与美国通胀挂钩；不是人民币通胀负债的完全匹配 |
| `bond.cn.ig` | 人民币投资级信用 | 排除已单列国债；中国评级与国际 IG 的可比性单列缺口，不把评级标签视作等风险 |
| `bond.usd.ig` | 美元投资级公司债 | “USD”是债务币种，不必等于美国发行人；美国组合另限美国发行人宇宙 |
| `equity.us` | 单一全球父宇宙的美国国家归属股票 | 与上市交易地、收入地区不同；含不含小盘由父宇宙固定 |
| `equity.cn.a` | 同一父宇宙中中国归属 A 股证券 | 纳入因子／自由流通限制明确；不是全体 A 股市场的无条件覆盖 |
| `equity.cn.offshore` | 同父宇宙中国归属、排除 A 股的证券 | H／红筹／P／N／其他合格上市线；不能用全体港股替代 |
| `equity.dm.ex_us` | 同父宇宙发达市场排除美国 | 是否含香港、市场分类迁移按确切版本；中国 offshore 不按上市港交所重新加入 |
| `equity.em.ex_cn` | 同父宇宙新兴市场排除中国 | 排除全部该体系中国归属证券；保留其他市场及其 FX |
| `gold` | 无杠杆、无借贷黄金现货经济暴露 | 地点、单位和基差；持有成本在工具层扣减 |
| `commodity.ex_gold` | 非黄金商品期货充分抵押篮子 | 指数合约、权重、展期、抵押币种和收益；黄金排除须真实可证 |

全球剩余名义主权、非美元信用、EM 本币债／硬通货债、HY 与上市实物资产是首轮候选扩展，不因“全球覆盖”强制进入起始优化矩阵。全球研究树覆盖它们；是否加入独立槽由研究问题、风险区分、合格序列和实施需求共同决定，不能直接把残余地区设零预期收益。

### 4.2 股票父宇宙和重叠检查

**建议起点为一个统一全球指数体系**（MSCI GIMI／ACWI 家族或 FTSE GEIS 家族，待选定），先确定国家归属和规模范围，再分区。ACWI 通常所称 large／mid 宇宙与包含小盘的 IMI 宇宙不得混名；World 是发达市场集合，不等于全球。不同体系的国家分类、纳入因子与规模覆盖可能不同，不能拿一个体系的美国和另一个体系的 ex-US 拼出“严格 ACWI”。[MSCI 方法目录](https://www.msci.com/indexes/index-resources/index-methodology)提供不同指数及计算方法入口；这里借其结构，具体父宇宙尚未冻结。

设父宇宙为 `U`，叶节点证券集合为 `U_i`，设计要求：

`U_i ∩ U_j = ∅ (i ≠ j)`；`∪U_i = U`，或明确列出未覆盖残余集合。

用上期父指数证券权重汇总区域：`r_U,t = Σ_i a_i,t−1 r_i,t`，其中 `a_i,t−1` 是按相同方法、收益与再平衡时点形成的父权重。该恒等式是**边界检查设计**，不是从若干公开月末权重必然精确还原官方指数的保证；日内事件和指数商计算细节仍需验证。ACWI／All-World 在模型中作为汇总参考或替代整个地区集合，两种模式只能选其一。

全球核心按国家归属分槽；美国／中国细看时，再挂规模、行业、风格、收入地区。FTSE 的编制规则区分中国不同上市线，并在公司规模排序中处理多证券线；此规则支持“公司和证券双层身份”的设计，但不能证明另一指数商处理完全一致。[FTSE GEIS Ground Rules](https://www.lseg.com/content/dam/ftse-russell/en_us/documents/ground-rules/ftse-global-equity-index-series-ground-rules.pdf)，本次网页版本 v14.4／September 2026，§7、Appendix A。

多上市地按以下四张概念账处理，不把它们混成一个国家字段：

| 归属账 | 记录与用途 |
| --- | --- |
| 发行人／国家账 | `issuer_id`、指数国家归属、总部／注册地等原始依据；每个叶槽使用统一规则 |
| 证券／权利账 | share class、A/H、普通股／ADR、存托比例、可转换关系；ADR 与对应普通股若是同一权益凭证，按方法避免双重证券纳入 |
| 市场／结算账 | 交易所、报价与结算币种、交易时钟、税费、流通与准入；A/H 为不同证券线，价格和交易限制不强求相同 |
| 经营暴露账 | 收入／成本／资产／利润地区及来源时点；用于宏观传导，不按收入比例把同一股票再当多笔持仓 |

发行人层集中度按所有 share class、存托凭证与基金穿透合计。美国上市中国 ADR 通常应按所选体系归入中国槽，而非因在美国成交就归入 `equity.us`；有归属争议时保留原始依据并暂停相关映射。美国公司中国收入多，不因此同时进入中国资本槽。A/H 的资本在证券层可分别持有，但合计发行人风险；不机械删除 H 股，也不把 A/H 当完全独立分散风险。

沪深300全收益可作为中国 A 股大盘**子集参考**，标明它与全球父宇宙中的中国 A 叶节点范围不同。纳指100、恒生科技、行业和红利指数是子集／风格倾斜，不增加“全新国家”。

### 4.3 美元美国组合

独立记录 `portfolio_scope = US`、`base_currency = USD`。基础候选为美元现金、美国名义国债期限桶、TIPS、美国发行人投资级信用、美国广义股票与美国上市房地产／基础设施卫星。黄金和全球商品可作为额外明确授权的经济暴露，不因为以美元报价而成为“美国资产”。美国组合若加入非美发行人债、海外股票或私募，须显式扩展地理范围。

人民币组合不能将同一 `μ/Σ` 换个货币标签就用于美元组合：FX、现金机会成本、套保成本、税与投资宇宙都可能不同。一个底层研究判断可复用，但每个组合的收益实现和约束独立。两个组合互为报告视角或属于同一投资人时，汇总净资产还要注明真实账户与重叠资本，不能把两个模型组合直接相加。

## 5. 现金、债券及解释因子的边界

### 5.1 现金与融资

现金槽应代表可持续滚动的实际资产收益，不以政策利率或到期收益率水平直接充当总收益序列。存款有银行信用和提前支取条件，回购有抵押／对手方／续作条件，货币基金有组合信用、费用和赎回规则；工具被称为“现金管理”不消除这些风险。

设计区分自由现金、已质押现金、衍生品保证金和未调用私募承诺备付。后两者仍是资产或负债管理项目，但可用性不同。现金收益归持有该现金的唯一账户；融资利息归借款／策略账户。无风险基准随计价币种和持有期绑定，不能拿人民币短期现金扣美元资产收益，也不能把短期绩效基准直接搬到公司长期 DCF。

### 5.2 债券收益和因子分解

先固定债券法律／现金流宇宙，再报告实际利率久期、关键期限久期、信用利差久期、凸性、币种与流动性。评级是筛选属性，不是跨国统一信用尺度。政策性、机构债及 MBS 与国债不同；综合 Agg 通常已有多类债券，不能再与其 Treasury／Corporate 子集并列作为互斥资本槽。

配置使用 TR／财富收益。解释可使用如下**局部近似设计**：

`r_bond,local ≈ carry + roll_down − Σ_k KRD_k Δy_k − SD Δs + ½ C(Δy)^2 − default_loss + residual`。

`Δy` 用小数利率变化，KRD 是关键期限久期，SD 是利差久期；在定义中固定国债曲线与利差，不把同一收益率变化既放入 `Δy` 又放入 `Δs`。carry、roll-down 与现金流再投资的估算规则需共同定义，不能在已有 TR 上再加票息／carry。含期权债须用合适的有效久期／凸性；大冲击、非平行曲线、评级迁移、违约、赎回与负凸性需另做情景，近似不替代真实收益。

中债财富、全价、净价分别有不同现金流处理；财富考虑再投资，全价含应计但已付息的后续处理不同，净价不含应计。因此正式配置不能把净价／全价指数当财富指数。[中债指数编制说明](https://indices.chinabond.com.cn/cbweb-mn/int/int_yield_zs_doc)，§二；具体指数再核查专门编制说明。

TIPS 是美国通胀指数挂钩的债券，实际利率上升仍可使其市价下跌；到期本金保护不保证任意购买价格或中途售价。它不是“实际收益永远为正”，也不能直接对冲人民币购买力。[美国财政部 TIPS 条款说明](https://treasurydirect.gov/marketable-securities/tips/)支持本金调整与到期条款；跨币种负债匹配是本设计的额外判断。

## 6. 黄金、商品、上市实物资产与策略池

### 6.1 黄金与商品

黄金现货价格没有股息或票息。若研究基准是价格回报，应明确其收益构造已完整表达所选现货暴露，不能为形式上的“全收益”随意增加现金利率。金矿股归权益；黄金期货、黄金租赁、实物 ETF 分别增加展期、融资、借贷或托管费用账。

非黄金商品核心候选采用明确期货合约和展期规则的充分抵押收益。现货／期货价格指标、ER 与 TR 必须区分：

- 价格或 spot 指标解释商品价格环境，并不代表实际采购、仓储或期货持有收益。
- 期货 ER 包含按规则持有／换月的期货损益；“展期收益”可以是分析分解项，不能在 ER 上再加一次。
- 充分抵押 TR 还包含约定的抵押收益；不能再叠加现金槽对应同一笔抵押资本的利息。

[S&P GSCI Methodology](https://www.spglobal.com/spdji/en/documents/methodologies/methodology-sp-gsci.pdf)及[官方计算简明指南](https://www.spglobal.com/spdji/en/documents/methodologies/methodology-sp-gsci-quick-guide.pdf)提供持仓／换月、ER 与抵押 TR 方法。指数方法支持区分这些收益组件，不能证明任一商品指数是唯一最合适的篮子。

`commodity.ex_gold` 的基准必须真实排除黄金。若只有含黄金的 broad commodity 指数，可以暂作研究参照，或按方法另建非黄金子篮子；在排除规则和历史未证实时不伪称互斥。若用户选择同时持有 broad commodity 与独立黄金，属于有意增配，按穿透后的总黄金权重披露，不称“两种独立资产完全不重叠”。农业、工业金属、能源与非黄金贵金属仍在研究树中保留。

### 6.2 上市房地产与基础设施

上市 REITs／基础设施指数与 broad equity 往往有交集。建议首个模型保留 broad equity，把专门指数作诊断或明确倾斜；若将其改成独立资本槽，须从普通权益槽剔除对应证券并构造同口径 ex 篮子，或保留资本 sleeve 后在风险和集中度账中完整穿透。两者是不同设计模式，不能混用后宣称资本叶节点互斥。

FTSE EPRA Nareit 研究的是上市房地产证券；FTSE Infrastructure 的选择规则研究上市公司经营活动。这些规则不代表直接物业或私募项目的收益。[EPRA 指数说明](https://www.epra.com/indexes)与[FTSE Infrastructure Ground Rules](https://www.lseg.com/content/dam/ftse-russell/en_us/documents/ground-rules/ftse-infrastructure-index-series-ground-rules.pdf)支持此边界。进一步研究租约、定价权、资本开支、经营杠杆、债务再融资和股权估值，不能只因收入长期就按债券风险处理。

直接房地产／基础设施需单独现金流与评估价方法。比如 NCREIF 的资产级 NPI 是私有商业地产、季度、无杠杆组合口径，而基金实际净回报可能有杠杆和费用；二者不能互换。[NCREIF 数据与指数说明](https://ncreif.org/indices/)为频率和资产／基金层差异的一手入口；具体序列方法和属性仍待核查。评估价的平滑、滞后与交易稀疏要研究，不把较小账面波动当更低经济风险。

### 6.3 对冲基金、CTA 与复杂策略

| 策略 | 合适研究对象 | 基准与入模边界 |
| --- | --- | --- |
| CTA／趋势 | 多市场期货趋势、持仓方向、波动目标、杠杆与保证金 | 趋势规则指数或经理指数分别列；不等于多头商品，可能含股指、利率和 FX；经理净值中的抵押利息／费用不可再加 |
| 全球宏观 | 方向／相对价值、跨资产、政策与 FX 判断 | 固定规则参照与经理选择分开；不能因名字叫宏观就具有稳定四象限回报 |
| 市场中性／股票多空 | 残余市场 beta、因子、空头借券、gross／net exposure、拥挤风险 | market neutral 名称不保证零 beta；经理指数和现金+目标只作各自含义的评价基准 |
| 相对价值／事件驱动／困境 | 利差、事件成功率、融资与流动性尾部 | 不与普通 IG／权益完全隔离；保留尾损和赎回条件 |
| 波动率／期权／结构化收益 | delta、gamma、vega、卖保险性质、路径和保证金 | 总收益不能只用底层价格替代；不把卖期权高胜率当低风险 |
| 固收+／股债混合／风险平价 | 底层权重、调仓、杠杆和风险控制规则 | 属配置策略；要么穿透到底层，要么作为一个 funded strategy sleeve 并披露重叠 |

HFRI 某些分类可包含同一基金，组合不同 HFRI 子指数会产生经理重叠；HFRX 等体系又有不同纳入规则。HFR 还区分初值、更新及最终值，基金报告为自愿提供，费用和 side pocket 口径需核查。[HFR Indices FAQ](https://www.hfr.com/hfr-indices/hfr-indices-faq/)。因此必须核验回填、幸存者、清盘基金及净费定义；不能以“有一条月序列”证明指数无偏或投资人能够完整复制。个别系列被指数商称为 investable，也仍需具体工具、准入与成本证明。

## 7. 私募、保险风险和数字资产的专门边界

### 7.1 私募现金流

PE／VC、私募债、直接房地产和私募基础设施须同时记录承诺、已投资 NAV、未调用承诺、资本调用、分配、费用与估值日。资本预算按已投资资本及备付政策建账；风险监测附未调用承诺和后续调用压力，不能用 NAV 权重隐去未来付款，也不能把完整承诺金额和对应现金同时算已投资净资产。

评价至少区分：同 vintage／策略／地区的同行比较，金额与时点敏感的 IRR／倍数，及按相同调用分配现金流构造的 PME。不能把基金 IRR 和上市股票 TWR 直接相减，也不能把年度 IRR 换算成“月收益”加入协方差。[Cambridge Associates 私募基准框架](https://www.cambridgeassociates.com/insight/a-framework-for-benchmarking/)支持现金流与公开市场等价比较；具体 PME 版本、残余 NAV 与失败情形须在后续设计选定。

经济风险可参考公开市场因子并做流动性、估值和杠杆压力，但代理必须标用途；不能用公开股票／REITs／IG 债替代私募收益历史，也不自动加固定流动性溢价。若未来使用季度 TWR 或去平滑估计，要保存完整方法和假设，与真实成交／现金流事实分开。

### 7.2 保险风险

Cat bonds 与抵押再保险的现金流由保险风险触发；利差不是普通企业信用利差。研究灾害类型、地区聚集、触发形式、模型版本、损失发展、再保价差、抵押及 trapped capital。巨灾债价格可以有可比基准，私募再保险则可能须现金流／估计损失口径。

Swiss Re Cat Bond 方法区分含／不含 FX 影响的指数，并计利息和价格变化。[Swiss Re Cat Bond Indices Methodology（2014）](https://www.swissre.com/dam/jcr%3A307452ca-9664-4772-96f9-7c11f80109b2/2014_08_ils_cat_bond_indices_methodology.pdf)仅用作历史方法参照；其中旧利率基准不能直接带入新设计，当前版本、评级、灾害覆盖、报价来源与合格序列均待核验。指数债券集合不能代表全部寿险或抵押再保险。

### 7.3 数字资产

观察池区分现货代币、期货、质押／借贷和稳定币。原生代币价格基准不包含质押收益、借贷利息、fork／airdrop 收益、托管成本或协议损失；要加入则单列策略方法。期货回报加展期／资金费率和抵押账，不能用现货价格替代。

S&P 的现货数字资产指数按其价格来源和流动性规则筛选；现货与期货系列不同。[S&P Cryptocurrency Index Series FAQ](https://www.spglobal.com/spdji/en/education/article/faq-sp-cryptocurrency-index-series/)。本设计据此要求精确定价场所、UTC 时钟、异常价规则、历史回填、停牌与退市；不据指数存在推定其合规、可托管或长期收益为正。稳定币有储备、发行人、赎回和脱锚风险，代币化国债按底层债券加包装风险归类。

### 8.2 TR、税、估值和历史回填

理论暴露可使用 GTR 表达税前经济总收益，账户表现另用 NTR／净费；正式模型若直接采用 NTR，所有相关槽必须说明税假设及差异。NTR 是指数商的标准预扣税假设，不代表人民币或美国投资人的实际税；不能再从 NTR 扣同一预扣税，也不能给 GTR 与 NTR 不同历史段无说明地拼接。FTSE GEIS §10 明确其 standard 与 net-of-tax 变体的税假设，实际账户需另外匹配。

指数平均收益、ETF 净值、市场成交价分别反映基准、净费及交易溢折价。工具评价可以与指数作 tracking difference；基金／ETF 缺少长历史时不能把指数历史说成基金真实可交易历史。债券估值价和私募评估价要标时间与可成交限制；缺报价不能无期限前值填充后产生“零波动”。

回算历史与推出后真实历史分段标记；现今成份股不能回推旧成份；事后生效的方法不证明历史时点可知。在未来旧截点研究中，必须区分“在该日公开可知的方法／成份／值”和“后来计算的该日指数历史”。回填可服务机制研究，不能未经说明充当 PIT 投资表现。短历史不以扩长样本为由拼代理；不合格序列只限制该槽，影响全组合约束或货币账时才暂停整个受影响输出。

## 9. 双币种、FX、套保与衍生品收益账

### 9.1 未套保回报

设 `B` 是组合本币，`L` 是资产收益计价币种，`X_t` 为“一单位 L 对应多少 B”；`r_L,t` 已包含所选资产的规定收入与再投资。无外部现金流时：

`1 + r_B,t = (1 + r_L,t) × X_t/X_t−1`。

FX 不是最后贴上的标签。若收到的公开指数本来已折算为 B，则直接使用该变体，不再乘一次 FX；若“USD global equity index”本身含多个底层币种，只换 USD→CNY 可以得到其 CNY 未套保计价回报，但套保设计还要回到各底层货币暴露，不能仅套一个 USD 远期就声称全球货币全部已对冲。

### 9.2 套保账与成本

人民币采用 CNY 的资产、外汇和账户规则；涉及 CNH 时另记可交割地点、基差、准入和资金成本，不默认为相同可交易币种。美元美国组合的本币资产通常没有换算 FX 项，海外经营收入仍有公司层汇率暴露，组合外汇套保不能自动消除它。

每个套保计划固定目标（本金／市值／负债）、比例 `h`、远期／期货／其他工具、币种、期限、重置、名义额、保证金及展期。一个期初卖出 L 的简化远期，在期末到期且无中途现金流时：

`r_B,hedged = (1+r_L)X_1/X_0−1 + N_L(F_0−X_1)/V_B,0 − costs_B/V_B,0`。

`F_0` 与 X 同为 B/L，`N_L` 是卖出 L 的名义额，`V_B,0` 是期初本币 NAV；若套保期初资产本金，则 `N_L = h V_B,0/X_0`。这是一期间教学公式，不是官方指数复制公式；期间估值、滚动、现金流和变动名义额须按采用方法处理。

远期点已经包含市场定价的利差／基差影响，不在 hedge P&L 之外再加同一笔“套保利差收益”。保证金／抵押现金收益和融资成本分别归实际账户；若已含在策略净值／指数方法里，不再扣／加一次。使用套保指数时核查其 hedge impact、成本和现金假设，与工具真实实施差额分开。[MSCI Hedged Methodology，August 2020](https://www.msci.com/eqb/methodology/meth_docs/MSCI_Hedged_Methodology_Aug2020.pdf)，§2 的月度远期方法仅作一手规则参考，采用新版本或不同币种变体仍须核查。

### 9.3 充分抵押、保证金和融资

选择以下一种资本账，不混用：

1. **funded TR sleeve**：整个商品／衍生策略槽包含其充分抵押资本和方法内利息；该资本不再次进入自由现金槽。
2. **overlay＋现金账**：底层现金资产归现金槽，期货／远期损益按组合期初 NAV 单独入账；名义暴露、保证金和可用现金另报。此时使用 ER／纯损益，不再叠加完整 TR。

同一期间、同一资本分母下，可写账面恒等式：

`r_sleeve = P&L_futures/V_0 + interest_collateral/V_0 − fees/V_0 − financing_cost/V_0`。

期货 P&L 已来自实际换月规则，不再额外加展期收益。TR 指数若以 USD 抵押，其转成 CNY 的 funded 回报会包含抵押的 USD FX；若实际用 CNY 抵押并只持美元商品期货，需要另建期货损益、现金与 FX 账，不能把 USD TR 的抵押利息机械替换为 CNY 利率就称精确复制。名义期货仓位不是同额 NAV；简单“现货资产权重和为一”的限制不能描述有杠杆 overlay。

### 9.4 两个纯假设教学例子

**例 1：同一资产在两种组合中的收益。** 假设某 USD 资产一期间美元总收益为 10%，期初 X=7 CNY/USD，期末 X=6.65，美元对人民币下跌 5%。美元组合该资产回报为 10%；人民币未套保回报按公式为 `1.10×0.95−1 = 4.5%`，不是 5%。再假设期初远期 F=7.07、全额对冲期初本金、无费用和保证金影响，其 hedge P&L 对期初 NAV 为 `(7.07−6.65)/7 = 6%`，人民币套保回报为 10.5%。它不刚好等于美元 10%，因为资产收益产生的新增 USD 没有被期初本金远期全部覆盖，并且有假设的远期点。全部数字为教学假设，未使用市场报价。

**例 2：一笔抵押资本只能赚一次利息。** 假设期初资本 100、期货本期间含换月的 P&L 为 3、该笔抵押现金利息为 0.2、无费用／融资，funded sleeve 回报为 `(3+0.2)/100 = 3.2%`。若模型使用这个 TR，又把同一 100 现金的 0.2 计入现金槽，合计 3.4% 就重复了利息。改为 overlay 账时，现金槽记 0.2，期货 overlay 记 3，分母仍是同一组合资本；这是另一种正确记账方式。这里不代表任何期货指数的实际回报或通常保证金比例。

## 10. 理论模型与实施约束的接口

经济研究负责暴露、机制、条件收益、风险、反证及缺口。实施负责账户能否获得该暴露，以及可交割、额度、税、费用、流动性、保证金、融资、赎回、托管和最小成交单位。研究覆盖某资产不等于允许账户买入；账户暂不能买入也不删除该资产的经济研究。

由资产设计交给后续组合设计的输入为：互斥核心叶槽及版本、候选基准口径卡、重叠／穿透映射、币种与套保规则、funded 或 overlay 选择、卫星与私募状态、收益资格和缺口。[数据口径与验证设计](04-数据口径与验证设计.md)中的 `return_snapshot / portfolio_version` 承载其采用版本、发布时间、估值时钟及输入资格；[研究接口与实施顺序](05-研究接口与实施顺序.md)承接采用、限制和更新。组合层根据具体典型约束方案决定可投资集合；不可行时说明替代暴露和偏离，不强行改底层研究预期以得到可行权重。

理论总收益到工具可实现收益的桥为“基准收益 → 跟踪差额／费用与税差 → 融资及抵押差 → 成交与结算差”，每笔组件须说明已含与未含。不能一边采用净费基金净值，一边再扣同一管理费；不能在资产 μ 内扣套保成本，又由 overlay 再扣。基准、模型组合、可实施组合和真实账户表现分别命名并保存。

宏观→行业→公司的接口复用国家、经营收入／成本币种、利率、通胀、信用、能源／金属暴露定义；指数涨跌不能代替行业需求／价格证据，也不能把“美国股票看好”直接映射到长飞收入增速。公司折现率仍按 SPEC 由公司作者独立采用期限、币种与风险溢价。
