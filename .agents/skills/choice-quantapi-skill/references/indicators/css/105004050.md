## 指标说明

下表是每个指标特有参数的说明，公共参数参见[css函数说明文档]<!-- agent only: (./../../functions/css.md)-->【3. 公共参数】部分。

|中文简称|英文简称|参数1|单位|精度|释义|
|---|---|---|---|---|---|
|单季度.销售净利率|QGPMARGIN|报告期[1]|%|0.0000|旧准则：(单季度.净利润+单季度.少数股东损益) / 单季度.主营业务收入净额   新准则：单季度.净利润 / 单季度.营业收入<!-- 目录：指数 / 财务指标 / 单季度财务指标 -->|
|单季度.销售毛利率|QNPMARGIN|报告期[1]|%|0.0000|旧准则：单季度.毛利 / 单季度.主营业务收入净额   新准则：单季度.毛利 / 单季度.营业收入<!-- 目录：指数 / 财务指标 / 单季度财务指标 -->|
|单季度.销售费用/营业总收入|QOPERATEEXPENSETOGR|报告期[1]|%|0.0000|单季度.销售费用占单季度.营业总收入的百分比。<!-- 目录：指数 / 财务指标 / 单季度财务指标 -->|
|单季度.营业收入同比增长率|QYOYGR|报告期[1]|%|0.0000|指定单季度营业收入相对上年该季度调整数的增长百分比。<!-- 目录：指数 / 财务指标 / 单季度财务指标 -->|
|单季度.营业收入环比增长率|QQOQGR|报告期[1]|%|0.0000|指定单季度营业收入相对上季度调整数的增长百分比。<!-- 目录：指数 / 财务指标 / 单季度财务指标 -->|
|单季度.归属母公司股东的净利润同比增长率|QYOYPNI|报告期[1]|%|0.0000|指定单季度归属母公司股东的净利润同比增长率相对上年该季度调整数的增长百分比。<!-- 目录：指数 / 财务指标 / 单季度财务指标 -->|
