# 01 宏观指标体系

原项目定位：为银行智能投顾月报（LLM 生成）及四大类资产配置模型选指标。覆盖中国宏观；海外只取原油、黄金、VIX 三个价格因子。

## 1. 指标挑选五原则

原项目最成熟、可原样复用的部分。判断一个指标是否进入核心池：

1. **服务决策与建模**：能改变业务输出（配置、解读、产品、持仓），或进入模型的输入／约束／状态识别／结果解释链路；两者都不能则不采。
2. **避免重复**：同一信息维度只留一个代表指标（多个宽基、相近期限利率、多个波动率、多个商品指数都属重复）。
3. **锚点优先**：优先市场公认锚点（沪深300、10Y 国债、VIX、黄金、原油、政策利率），降低跨团队与对客解释成本。
4. **长期稳定**：历史 ≥10 年（最好 ≥20 年）、口径连续、不易停更，能支持跨周期回测与参数估计。
5. **可解释、可传导**：能说明「发生了什么 → 影响哪类资产 → 影响哪些产品／公司 → 如何解释持仓／估值」。

删除标准即五条的反面：不服务决策、与已有指标重复、非锚点、历史短或口径不稳、无法传导。

> 迁移到估值链路时，第 5 条的传导终点由「产品与持仓」换成「行业需求／价格 → 公司收入、毛利率、折现参数」。

## 2. 分析框架

### 2.1 三主线

卖方宏观模板（经济总量／价格／工业消费／投资地产／财政民生／进出口／货币／信用）收敛为三条主线：

```text
经济 → 股票       通胀 → 商品／黄金       利率／信用 → 债券       流动性 → 现金
```

原项目对卖方模板的自评：覆盖全、适合写报告，但维度过多、指标冗余（PMI／工业／GDP 互相重叠）、口径不统一、缺资产映射，不宜直接喂量化模型。

### 2.2 四模块（落地版）

| 模块 | 决定什么 | 核心指标 | 链路 |
| --- | --- | --- | --- |
| 增长 + 景气 | **方向** | GDP、制造业 PMI、非制造业 PMI、工业增加值；失业率辅助 | 指标 → 景气 → 周期阶段 → 趋势 → 股票 β |
| 通胀 + 商品 | **利率** | CPI、PPI、布油、黄金 | 指标 → 通胀状态 → 价格传导 → 利率预期 → 资产影响 |
| 流动性 + 信用 | **估值**（最关键） | M1、M2、社融存量、DR007、国债 1Y／10Y、LPR、准备金率、AA 信用债 | 指标 → 流动性 → 信用扩张 → 金融条件 → 全资产 |
| 需求结构 | **结构**（行业／风格） | 社零、消费者信心、居民收入；基建／制造／地产投资、住宅销售、房价；进出口、新出口订单、汇率；财政支出、专项债 | 指标 → 需求拆解 → 驱动结构 → 经济贡献 → 行业映射 |

每个模块输出统一结构（示例）：

```json
{
  "module": "需求结构",
  "state": "内需走弱 + 外需支撑",
  "trend": "恶化",
  "driver": ["地产拖累", "消费走弱", "出口稳定"],
  "asset_impact": {"消费": "偏空", "地产链": "偏空", "出口链": "支撑"}
}
```

模块作者的五项职责：指标经济含义、信号规则（阈值／趋势）、状态机（上行／下行／拐点）、结构化解读、资产映射。三条禁止：不跨模块解释、不输出无资产映射的结论、不只写数据不下判断。

总提示词拼装：`[四个模块输出] → Step 1 宏观阶段判断 → Step 2 核心矛盾识别 → Step 3 资产方向判断`。

> 原项目只设计了这套结构，没有真正实现「模块各自产出 JSON 再汇总」；最终月报是把全部原始数据一次性喂给模型（见 `03`）。

## 4. 口径规则

- **日频 → 月频**：宏观输入主要用**月均值**（代表当月整体环境）；AA 企业债 3Y、国债 3Y 实际用**月内最后有效值**（表示观察时点）。资产建模用**月末值**（收益率需要时点价格）；采用口径须在定义层写明。
- 当月未结束时的月均值是部分月份均值，原项目未标注，复用时须标记或剔除。
- **同比、累计同比、50 阈值类、指数水平类**可直接喂原值；**累计值**转进度、当月新增或同比再喂；**年度目标**只作分母或年度锚。
- NBS 投资、社零等 1–2 月合并发布，1 月为空；月报中这一空缺未向模型说明。
- `NULL` 表示尚未发布，不填 0 或均值。
- 统计修订：追加新 `data_version`，不覆盖；查询取最大版本。
- 口径变更必须登记（原项目：2026-04-08 社零由累计同比改当月同比）。

## 5. 宏观 → 资产映射

### 5.1 驱动维度

| 驱动 | 核心指标 | 含义 | 主要影响 |
| --- | --- | --- | --- |
| 增长 | GDP、PMI_MANU、PMI_SERV、INDUSTRY_YOY | 增长趋势、景气、生产修复 | 股票、商品、部分信用债 |
| 通胀 | CPI、PPI、BRENT | 居民通胀、工业品价格、输入性通胀 | 债券、商品、黄金 |
| 流动性 | M2、M1、DR007 | 资金松紧、货币环境、短端成本 | 股票、债券、黄金 |
| 信用 | 社融存量、AA 3Y 收益率 | 信用扩张、融资条件、信用风险溢价 | 股票、信用债、固收+ |
| 利率 | 国债 1Y／10Y、LPR | 无风险利率、期限结构、政策利率 | 债券、股票估值、黄金 |
| 外部与风险偏好 | 汇率、黄金、VIX | 汇率冲击、全球避险、海外波动 | 黄金、股票、外向型资产 |

### 5.3 预期差思路（未实现、未验证）

原项目一份供应商材料提出「实际值 − 机构一致预期」的预期差框架：单期预期差、多期预期差动量、按增长／流动性／通胀超预期判断资产方向。思路可取，但原项目**没有接入一致预期数据**，材料中的量化结论（如「超额收益约 5.56%」「连续三期 PPI 超预期后商品胜率 68%」「PPI 预期与原油相关 0.73」「油气与美股相关 -71.8%」）均无出处与回测，只能当待验证假设。
