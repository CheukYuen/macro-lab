## 结论

**你的猜测大约 70% 是对的。**

真正的问题不是“大类资产分析在中国有没有用”，而是：

> **不能用一张“股债商现金相关性矩阵”，同时解决宏观判断、战略配置、行业轮动和个股选择四个问题。**

大类框架在中国依然有用，但主要价值是：

1. 判断组合当前承担了什么宏观风险；
2. 控制权益、利率、信用、通胀和流动性风险；
3. 给行业和个股投资设定风险预算；
4. 防止看似持有很多资产，实际风险全部来自同一个方向。

它通常**不是强前瞻收益模型**，更不是靠“美林时钟”直接获得高收益的模型。

**不是用科创50和红利取代沪深300，而是把它们放到不同层。**

## 2. “细分以后，相关性还有没有意义？”

**有意义，而且比大类矩阵更接近实际投资，但不能只看长期静态相关性。**

| 资产 | 核心风险 |
|---|---|
| 科创50 | 利率久期、科技资本开支、风险偏好、估值 |
| 红利 | 利率、国企政策、盈利稳定性、商品价格 |
| 消费 | 居民收入、地产财富效应、内需 |
| 半导体 | 全球周期、库存、出口限制、资本开支 |
| 金融 | 信贷周期、净息差、资产质量 |
| 周期 | PPI、基建、房地产、全球需求 |

所以细分相关性能够回答：

- 科创与红利是否真正分散；
- 半导体和通信是不是重复暴露；
- 黄金和资源股是不是同时押注商品；
- 银行、保险、红利指数是否实际上是同一类风险；
- 多个行业ETF是否只是“换了名字的权益Beta”。

但要注意：

> 股票行业之间的相关性，在平稳时期可能较低，市场下跌时往往同时上升。

中国行业间存在明显的动态风险传导，极端事件期间行业联动通常增强，因此单一长期相关矩阵容易高估分散效果。

应当至少同时看：

```text
长期相关性：结构性分散
近三年相关性：当前市场结构
近一年相关性：近期拥挤与风险偏好
下跌期相关性：真正的尾部保护
因子相关性：是否只是名称不同、风险相同
```

## 4. “大类分析不具备前瞻性，只能稳定低收益”

**部分正确。**

传统大类配置通常不擅长预测：

- 下个月股票涨跌；
- 科创50什么时候启动；
- 哪个行业下周成为主线；
- 某只股票什么时候突破。

因为宏观数据存在：

- 发布滞后；
- 数据修订；
- 经济与市场不同步；
- 政策反应内生；
- 市场提前交易预期；
- 同一宏观状态可能对应不同市场表现。

所以简单模型：

```text
经济上行 + 通胀上行 → 买商品
经济下行 + 通胀下行 → 买债券
```

在中国并不足够可靠。

但这不代表大类分析没有前瞻价值。它更适合预测：

- 什么资产当前更脆弱；
- 哪种风险可能被错误定价；
- 哪种组合在某个宏观场景下会一起亏；
- 当前应当增加还是减少风险预算；
- 应该偏向利率资产、价值、成长还是周期。

中国股债相关性并不是固定的。基于2002—2024年数据的一项研究发现，动态股债相关性曾在约 -0.6 至 +0.3 之间变化，利率、通胀、股市波动和政策不确定性都会改变相关关系。

因此大类模型应该输出：

```text
概率、场景、风险预算、上下限
```

而不是：

```text
精确点位、单一方向、满仓空仓信号
```

## 5. “可用于判断宏观周期、货币、利率、出口对股票的影响”

**这是大类分析在中国最有价值的部分。**

但不要把宏观变量直接映射成指数涨跌，而要映射成三个渠道：

### 现金流渠道

宏观变化影响企业利润：

```text
出口订单 → 出口制造收入
房地产 → 建材、家电、银行资产质量
PPI → 上游资源品利润
居民收入 → 消费企业收入
资本开支 → 半导体、设备、工业软件
```

### 折现率渠道

利率和流动性影响估值：

```text
实际利率下降
    → 长久期成长资产估值改善
    → 科技成长通常更敏感

信用利差扩大
    → 风险资产估值承压
    → 小盘、弱现金流公司更敏感
```

### 风险偏好渠道

政策、汇率和市场流动性影响风险溢价：

```text
政策不确定性上升
    → 风险溢价提高
    → 即使盈利没有变化，估值也可能下降
```

所以宏观模块应当是**行业和股票模型的条件变量**，而不是直接代替行业和个股研究。

## 第三层：个股因子矩阵

- 权重极端化；

- 样本外完全失效。

```text
个股收益
= 市场Beta
+ 行业因子
+ 规模因子
+ 价值因子
+ 动量因子
+ 质量因子
+ 特质收益
```

然后控制：

```text
行业偏离
风格偏离
个股上限
流动性
换手率
尾部风险
```
