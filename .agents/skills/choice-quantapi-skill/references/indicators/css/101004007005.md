## 指标说明

|非流动资产/总资产|NCATOASSET|报告期[1]|%|0.0000|反映总资产构成的指标。流动资产/总资产+非流动资产/总资产=1。<!-- 目录：股票 / 三板股指标分类 / 财务分析 / 资本结构 -->|
|有形资产/总资产|TANGIBLEASSETSTOASSET|报告期[1]|%|0.0000|有形资产净值占总资产百分比。<!-- 目录：股票 / 三板股指标分类 / 财务分析 / 资本结构 -->|

|非流动负债/负债合计|NCLTOLIBILITY|报告期[1]|%|0.0000|反映债务结构的指标。流动负债/负债合计+非流动负债/负债合计=1。<!-- 目录：股票 / 三板股指标分类 / 财务分析 / 资本结构 -->|
