# Choice EDB 宏观指标 ID 对照

用途：用 Choice 量化 API（EMQuantAPI）的 `c.edb` 取宏观序列时，按此表找 ID。

机器读的版本是同目录的 `choice-edb.csv`，脚本只从 CSV 取 ID（`macrolab.ids`）。增删 ID 时两处一起改，然后跑 `uv run python -m macrolab.ids --check` 核对一致。

## 来源与核验状态

- 候选 ID 来自 `docs/imports/landing-zone-macro/01-宏观指标体系.md`、`docs/imports/claude-macro-framework-20261014/indicators.csv`，以及 invest-lab `runs/chinabond-channel-20261012/choice-diagnosis/`（国债曲线）。这些都是未经审核的候选材料。
- **2026-10-16 已用 `c.edbquery` 逐个核对官方名称、频率和起止日期**（SDK V2.7.5.0）。下表"官方名称"一列照抄返回值。
- 只核对了元数据，**数值还没有和官方发布对照过**。指标选用与口径取舍仍按 HANDOFF 的议程讨论，不因列在本表就算采纳。

## 调用要点

- `c.edb` / `c.edbquery` 一次只能放同一前缀的 ID（EMM、EMI、EMG、E1 不能混在一起），混用会报 `10003003 edbids can't be mixed`。
- `edbquery` 返回的字段：ID、NAME、UNIT、SOURCE、REGION、FREQUENCY、STARTDATE、ENDDATE、UPDATETIME。
- FREQUENCY 代码按返回的日期格式推断：1=日，5=月，6=季，8=年。这是推断，没有查到官方文档。
- skill 文档 `.agents/skills/choice-quantapi-skill` 没有 `edb` 的函数说明；用之前先看 SDK 自带的 docstring，或者试跑一次。
