## 指标说明

下表是每个指标特有参数的说明，公共参数参见[css函数说明文档]<!-- agent only: (./../../functions/css.md)-->【3. 公共参数】部分。

|中文简称|英文简称|参数1|参数2|单位|精度|释义|
|---|---|---|---|---|---|---|
|全部投入资本|TOTALCAPITAL|报告期[1]||元|0.0000|投入资本指所有投资者（股权人、债权人）投入的资金总和，这些资金都是意图分享企业经营回报的。投入资本与总资产的核心差别在于投资资本中不包含无息负债。<!-- 目录：股票 / 沪深京股票指标 / 财务分析 / 衍生报表数据 / 基于资产负债表 -->|
|营运资本|WORKINGCAPITAL|报告期[1]||元|0.0000|营运资本是指流动资产减去流动负债后的余额，是按照账面价值将流动性资产转换成现金清偿全部流动性负债后，剩余的货币量。营运资金越多，意味着企业偿还短期债务的可能性越大。<!-- 目录：股票 / 沪深京股票指标 / 财务分析 / 衍生报表数据 / 基于资产负债表 -->|
|净营运资本|NETWORKINGCAPITAL|报告期[1]||元|0.0000|净营运资本，又称“营业流动资本”，反映企业需要投入的用于流转的资金数额。<!-- 目录：股票 / 沪深京股票指标 / 财务分析 / 衍生报表数据 / 基于资产负债表 -->|
|有形资产|TANGIBLEASSET|报告期[1]||元|0.0000|有形资产净值，简称有形净值，是股东权益减去无形资产净值后的实物资产账面价值。<!-- 目录：股票 / 沪深京股票指标 / 财务分析 / 衍生报表数据 / 基于资产负债表 -->|
|留存收益|RETAINED|报告期[1]||元|0.0000|留存收益是指企业经营过程中内部积累的资本，它包括按规定从税后利润中提取的盈余公积金和未分配利润。<!-- 目录：股票 / 沪深京股票指标 / 财务分析 / 衍生报表数据 / 基于资产负债表 -->|
|带息债务|INTERESTLIBILITY|报告期[1]||元|0.0000|有偿使用的债务资本。<!-- 目录：股票 / 沪深京股票指标 / 财务分析 / 衍生报表数据 / 基于资产负债表 -->|
|净债务|NETLIBILITY|报告期[1]||元|0.0000|净债务指的是短期和长期带息债务之和减去现金及现金等价物后的余值，扣除现金及现金等价物是因为这部分资产可以随时用来偿还债务。<!-- 目录：股票 / 沪深京股票指标 / 财务分析 / 衍生报表数据 / 基于资产负债表 -->|
|无息负债|EXINTERESTDEBT|报告期[1]|报表类型[2]|元|0.0000|见算法<!-- 目录：股票 / 沪深京股票指标 / 财务分析 / 衍生报表数据 / 基于资产负债表 -->|
|无息流动负债|EXINTERESTCL|报告期[1]||元|0.0000|无息流动负债在资产负债表中主要表现为应付账款、应付工资、其他应付等。无息流动负债也是企业对其他方资金的一种占用，但这部分资金并不来自于投资人，这种资金占用只是企业正常经营活动中的一个必要环节，一种循环占用。<!-- 目录：股票 / 沪深京股票指标 / 财务分析 / 衍生报表数据 / 基于资产负债表 -->|
|无息非流动负债|EXINTERESTNCL|报告期[1]||元|0.0000|无息非流动负债在资产负债表中主要体现为预计负债、长期应付款等。为了谨慎起见，我们采用间接法计算无息非流动负债。<!-- 目录：股票 / 沪深京股票指标 / 财务分析 / 衍生报表数据 / 基于资产负债表 -->|

## 参数说明

> 默认值中以**获取规则**开头的内容，需要按照规则获取相应日期作为默认值。

|参数编号|英文简称|中文说明|取值范围|默认值|
|---|---|---|---|---|
|1|ReportDate|报告期||获取规则：去年年报|
|2|Type|报表类型|1 合并报表<br>2 母公司报表<br>3 合并报表（调整）<br>4 母公司报表（调整）|1|
