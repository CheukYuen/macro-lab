## 指标说明

下表是每个指标特有参数的说明，公共参数参见[css函数说明文档]<!-- agent only: (./../../functions/css.md)-->【3. 公共参数】部分。

|中文简称|英文简称|参数1|参数2|单位|精度|释义|
|---|---|---|---|---|---|---|
|寿险内含价值EV|EV|报告期[1]|币种[2]|||港股的寿险内含价值。<!-- 目录：股票 / 港股及美股指标 / 财务分析(旧) / 保险业专项指标 -->|
|集团内含价值EV|GEV|报告期[1]|币种[2]|||港股的集团(总)内含价值。注：若公司公告中未区分内含价值的种类(如，总内含价值，集团内含价值，寿险内含价值和健康内含价值等)，则归为集团(总)内含价值。<!-- 目录：股票 / 港股及美股指标 / 财务分析(旧) / 保险业专项指标 -->|
|每股内含价值EVPS|EVPS|报告期[1]|币种[2]|||期末每股内含价值。注：若当前指标没有数据，可参考每股总内含价值指标（因为部分公司没有披露寿险内含价值）。<!-- 目录：股票 / 港股及美股指标 / 财务分析(旧) / 保险业专项指标 -->|
|每股总内含价值EVPS|GEVPS|报告期[1]|币种[2]|||期末每股集团(总)内含价值。<!-- 目录：股票 / 港股及美股指标 / 财务分析(旧) / 保险业专项指标 -->|
|内含价值PEV|PEV|报告期[1]||||内含价值PEV=总市值/内含价值。<!-- 目录：股票 / 港股及美股指标 / 财务分析(旧) / 保险业专项指标 -->|

## 参数说明

> 默认值中以**获取规则**开头的内容，需要按照规则获取相应日期作为默认值。

|参数编号|英文简称|中文说明|取值范围|默认值|
|---|---|---|---|---|
|1|ReportDate|报告期||获取规则：最新一期（MRQ）|
|2|CURTYPE|币种|1 原始币种<br>2 人民币<br>3 美元<br>4 港元<br>5 英镑|1|
