# 截面函数 / 指数 / 股本指标

## 指标说明

下表是每个指标特有参数的说明，公共参数参见[css函数说明文档]<!-- agent only: (./../../functions/css.md)-->【3. 公共参数】部分。

|中文简称|英文简称|参数1|单位|精度|释义|
|---|---|---|---|---|---|
|总股本|TOTALSHARE|截止日期[1]|||指数样本股的总股本之和<!-- 目录：指数 / 股本指标 -->|
|自由流通股本|FREELIQSHARE|交易日期[2]|股|0.0000|自由流通股本  注：目前仅支持中证指数。<!-- 目录：指数 / 股本指标 -->|
|流通股本|LIQSHARE|截止日期[1]|||指数流通股本是指指数样本股流通股本之和，如果样本股是A股则流通股本是流通A股，如果样本股是B股则流通股本是流通B股<!-- 目录：指数 / 股本指标 -->|

## 参数说明

> 默认值中以**获取规则**开头的内容，需要按照规则获取相应日期作为默认值。

|参数编号|英文简称|中文说明|取值范围|默认值|
|---|---|---|---|---|
|1|EndDate|截止日期||获取规则：最新日期|
|2|TradeDate|交易日期|字符串，支持YYYYMMDD,YYYY-MM-DD,YYYY/MM/DD，例：20160101|获取规则：最新日期|
