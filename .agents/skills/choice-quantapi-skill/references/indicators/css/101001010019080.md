> 默认值中以**获取规则**开头的内容，需要按照规则获取相应日期作为默认值。

|参数编号|英文简称|中文说明|取值范围|默认值|
|---|---|---|---|---|
|1|ReportDate|报告期||获取规则：最新一期（MRQ）|
|2|Type|报表类型|1 合并报表<br>2 母公司报表<br>3 合并报表（调整）<br>4 母公司报表（调整）|1|
|3|DataType|数据类型|1 本币<br>2 本外币<br>3 外币|2|
|4|IndustryName|行业名称|C 制造业<br>F 批发和零售业<br>G 交通运输、仓储和邮政业<br>K 房地产业<br>D 电力、热力、燃气及水生产和供应业<br>E 建筑业<br>B 采矿业<br>I 信息传输、软件和信息技术服务<br>H 住宿和餐饮业<br>A 农、林、牧、渔业<br>J 金融业<br>N 水利、环境和公共设施管理业<br>L 租赁和商务服务业<br>P 教育<br>Q 卫生和社会工作<br>M 科学研究和技术服务业<br>O 居民服务、修理和其他服务业<br>R 文化、体育和娱乐业<br>S 综合<br>T 其他行业|C|
