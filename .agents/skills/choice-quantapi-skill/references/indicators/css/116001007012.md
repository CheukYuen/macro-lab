|中文简称|英文简称|参数1|参数2|单位|精度|释义|
|---|---|---|---|---|---|---|
|总赚钱|TOTALEARNING|报告期[1]||||在公司特定期间内总共赚到了多少货币资金，而不关注这些赚到的钱又用到哪里。也就是说，表明期间的赚钱总数，但看不出赚到以后怎么用，即不区分本期是否用到增量投资上还是原封不动。<!-- 目录：机构 / 券商指标 / 财务分析 / 现金流诊断指标 -->|
|净赚钱|NETEARNING|报告期[1]||||更严格的业绩评价指标。只看公司是不是为股东赚出来增量货币资金，对用货币资金换来的非货币资产视而不见。<!-- 目录：机构 / 券商指标 / 财务分析 / 现金流诊断指标 -->|
|年初未分配总赚钱|UNDISTRITOTALEARNING|报告期[1]||||表示某一时点上公司财富积累的指标。不是指从股东或债权人那里得到多少钱，而是指在这些条件支持下，公司自己的积蓄如何，不是看"资本集中"，而是看“资本积累”。年初，即对应报告期上年年末值。<!-- 目录：机构 / 券商指标 / 财务分析 / 现金流诊断指标 -->|

## 参数说明

> 默认值中以**获取规则**开头的内容，需要按照规则获取相应日期作为默认值。

|参数编号|英文简称|中文说明|取值范围|默认值|
|---|---|---|---|---|
|1|ReportDate|报告期||获取规则：最新一期（MRQ）|
|2|TradeDate|交易日期|字符串，支持YYYYMMDD,YYYY-MM-DD,YYYY/MM/DD，例：20160101|获取规则：最新日期|
|3|Type|报表类型|1 合并报表<br>2 母公司报表<br>3 合并报表（调整）<br>4 母公司报表（调整）|1|
