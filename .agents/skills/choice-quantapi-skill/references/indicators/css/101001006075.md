## 指标说明

下表是每个指标特有参数的说明，公共参数参见[css函数说明文档]<!-- agent only: (./../../functions/css.md)-->【3. 公共参数】部分。

|中文简称|英文简称|参数1|参数2|单位|精度|释义|
|---|---|---|---|---|---|---|
|总市值|MV|交易日期[1]||||按照个股市价和总股本计算的市值。<!-- 目录：股票 / 沪深京股票指标 / 估值指标 / 不可回测估值 -->|
|市盈率PE|PE|交易日期[1]|财务数据匹配规则[2]|||每股市价为每股收益的倍数。反映投资人对每元净利润所愿支付的价格，用来估计股票的投资报酬和风险。<!-- 目录：股票 / 沪深京股票指标 / 估值指标 / 不可回测估值 -->|
|市净率PB|PB|交易日期[1]|财务数据匹配规则[3]|||按照指定日期所选股票的人民币收盘价计算的公司总市值与同期公司账面净资产的比值。<!-- 目录：股票 / 沪深京股票指标 / 估值指标 / 不可回测估值 -->|
|市销率PS|PS|交易日期[1]|财务数据匹配规则[2]|||每股市价为每股销售额的倍数。<!-- 目录：股票 / 沪深京股票指标 / 估值指标 / 不可回测估值 -->|
|市现率PCF(经营现金流)|PCFCFO|交易日期[1]|财务数据匹配规则[2]|||每股市价为每股经营性现金流的倍数。<!-- 目录：股票 / 沪深京股票指标 / 估值指标 / 不可回测估值 -->|
|市现率PCF(现金净流量)|PCFNCF|交易日期[1]|财务数据匹配规则[2]|||每股市价为每股现金净流量的倍数。<!-- 目录：股票 / 沪深京股票指标 / 估值指标 / 不可回测估值 -->|
|市研率PRR(LYR)|PRR|交易日期[1]||||市研率反映公司股价与公司研发的简单算术关系。注意：“按公告日”有别于“按报告期”。若“按报告期”则只能用最近一期的年报。“按公告日”当无法取到最近一期年报时，可以取到以前已公布的年报。<!-- 目录：股票 / 沪深京股票指标 / 估值指标 / 不可回测估值 -->|
|历史PEG值|PEG|交易日期[1]|财务数据匹配规则[2]|-|0.0000|PEG值，常用估值指标之一，结合考虑了目标企业的市盈率水平和未来盈利成长性。    通常，PEG的算法是公司市盈率(PE)除以公司未来3或5年的每股收益复合增长率。我们这里将算法简化为市盈率除以公司未来1年的净利润增长率。<!-- 目录：股票 / 沪深京股票指标 / 估值指标 / 不可回测估值 -->|

## 参数说明

> 默认值中以**获取规则**开头的内容，需要按照规则获取相应日期作为默认值。

|参数编号|英文简称|中文说明|取值范围|默认值|
|---|---|---|---|---|
|1|TradeDate|交易日期|字符串，支持YYYYMMDD,YYYY-MM-DD,YYYY/MM/DD，例：20160101|获取规则：最新日期|
|2|type|财务数据匹配规则|2 前年年报<br>1 上年年报<br>3 当年一季×4<br>4 当年中报×2<br>5 当年三季×4/3<br>6 当年年报<br>7 最新年报(LYR)<br>8 上年三季×4/3|1|
|3|type|财务数据匹配规则|2 前年年报<br>1 上年年报<br>3 当年一季<br>4 当年中报<br>5 当年三季<br>6 当年年报<br>7 最新年报(LYR)<br>8 最新报告期(MRQ)<br>9 上年三季<br>10 最新公告|8|
